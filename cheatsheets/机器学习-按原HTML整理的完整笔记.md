# 【机器学习01】监督学习、无监督学习、线性回归、代价函数

对应原文件：[第01篇 HTML](<吴恩达机器学习完整笔记/【机器学习01】监督学习、无监督学习、线性回归、代价函数 p1-p9.html>)。

## 一、监督学习

### 1.1 什么是监督学习

**监督学习（Supervised learning）**：使用带有正确答案的数据，学习输入到输出的映射，再用这个映射预测新样本的输出。

一个训练样本通常写为 $$(x, y)$$：$$x$$ 是输入信息，$$y$$ 是与输入对应的真实标签。例如，$$x$$ 是房屋面积，$$y$$ 是实际成交价。“监督”体现在训练时能够用真实答案评价预测，并据此调整模型。

需要区分三个对象：**数据**提供例子，**学习算法**规定怎样利用例子调整参数，**模型**是训练得到的预测函数。训练完成后，新房屋的真实成交价通常未知，但仍然可以输入它的面积，让模型给出预测。

### 1.2 监督学习的应用实例

| 应用 | 输入 $$x$$ | 标签或目标 $$y$$ |
|---|---|---|
| 垃圾邮件识别 | 邮件文本、发件人等特征 | 是否为垃圾邮件 |
| 语音识别 | 一段音频 | 对应的文字 |
| 机器翻译 | 一种语言的句子 | 另一种语言的句子 |
| 广告点击预测 | 用户、广告、上下文信息 | 是否点击 |
| 自动驾驶中的目标识别 | 图像、传感器数据 | 车辆、行人等目标信息 |
| 生产缺陷检测 | 产品照片或检测数据 | 是否存在缺陷 |

这些问题的共同点是：训练数据包含输入以及对应的目标。输入不一定是一个数字，也可以是图像、声音、文本或多个变量。

### 1.3 监督学习的两种类型

按照**要预测的输出是什么**，课程把监督学习的基础任务分为回归与分类。

#### 1.3.1 回归（Regression）

**回归**预测数值型结果，例如房价、温度、销量。房价预测中，面积是输入，价格是输出；输出可以在某个范围内连续变化。

回归要回答的是“多少”。预测结果为 42.5 万元和 43 万元，表达的是数值大小上的不同，而不是两个不同类别。

#### 1.3.2 分类（Classification）

**分类**预测离散类别，例如良性/恶性、垃圾邮件/正常邮件、数字 0～9。只有两个类别时称为**二分类**，超过两个类别时称为**多分类**。

用 $$0$$、$$1$$ 表示类别只是编码，不意味着类别间具有普通数值的大小关系。分类模型也可以先输出概率，再通过阈值或最大概率决定类别。

特征可以有多个。例如用“肿瘤大小”和“患者年龄”共同预测肿瘤类别；此时模型在特征空间中划出**决策边界**，边界两侧对应不同预测。

### 1.4 总结

| 概念 | 含义 | 房价示例 |
|---|---|---|
| 样本 | 一条完整观测记录 | 一套房屋及其成交信息 |
| 特征 $$x$$ | 用于预测的输入变量 | 面积、卧室数、房龄 |
| 标签 $$y$$ | 训练时提供的真实答案 | 实际成交价 |
| 预测值 $$\hat y$$ | 模型根据输入给出的结果 | 预测成交价 |

**回归与分类的区别由目标的含义决定，不由输入特征的个数决定。**

## 二、无监督学习

### 2.1 监督学习 vs 无监督学习

**无监督学习（Unsupervised learning）**：训练数据没有针对当前任务提供的目标标签，算法尝试发现数据自身的结构、分布或规律。

| 对比项 | 监督学习 | 无监督学习 |
|---|---|---|
| 训练数据 | 通常有 $$(x, y)$$ | 通常只有 $$x$$ |
| 主要目标 | 学习输入与标签的关系 | 发现数据内部结构 |
| 例子 | 根据已标注邮件学习垃圾邮件识别 | 将没有类别标注的文章分组 |

“没有标签”不等于“没有任何评价标准”。聚类仍然有组内距离等优化目标，只是这些目标不依赖每个样本的正确类别标签。

### 2.2 聚类（Clustering）

**聚类**：按照相似性把数据划分成若干组，每一组称为一个**簇（cluster）**。期望同一簇内的数据较相似，不同簇之间差异较明显。

分类使用预先给定的类别训练；聚类通常没有这些类别标签，分组结构由数据和算法共同决定。聚类所得“第 1 簇”没有天然业务含义，需要结合样本再解释。

#### 2.2.1 聚类的应用实例

- **新闻分组**：把描述同一事件或相似主题的文章聚在一起。
- **用户分群**：按购买行为划分用户群，辅助制定不同服务策略。
- **基因数据分析**：寻找表达模式相近的基因或样本。
- **天文数据分析**：按观测特征组织天体，发现可能存在的类别结构。

分组是否有用，取决于特征、距离定义和业务目的；算法不会自动保证每个簇都对应一个真实世界类别。

### 2.3 其他无监督学习算法

**降维（Dimensionality reduction）**：用更少的变量表示数据，同时尽量保留重要信息。常用于可视化、压缩、减少冗余；第14篇介绍 PCA。

**异常检测（Anomaly detection）**：识别明显偏离正常模式的样本，例如异常服务器、可疑交易。课程主要介绍通过正常数据估计分布的方法，见第12、13篇。异常检测也可以使用监督方法，不能把所有异常检测都限定为无监督学习。

### 2.4 小结与思考

判断任务类型时，先问“训练数据提供什么”和“希望输出什么”。预测房价属于监督回归；预测客户是否流失属于监督分类；没有流失标签，只按客户行为分组，则是聚类。

推荐系统是一个**应用领域**，其中既可以使用监督学习，也可以使用协同过滤等方法，不应与“监督、无监督、强化学习”简单并列为同一层级。

## 三、线性回归模型

### 3.1 回顾：什么是回归问题

**线性回归（Linear regression）**用输入特征的线性组合预测数值。只有一个输入特征时，预测函数在平面上是一条直线。

房价示例中，给定一组面积与真实价格，希望找到一条尽可能贴近这些样本的直线，以预测新房屋的价格。

### 3.2 模型的专业术语

| 符号 | 含义 | 注意 |
|---|---|---|
| $$m$$ | 训练样本数 | 数据有多少行 |
| $$n$$ | 每个样本的特征数 | 数据有多少个输入变量 |
| $$x^{(i)}$$ | 第 $$i$$ 个样本的输入 | 上标 $$(i)$$ 是索引，不是乘方 |
| $$y^{(i)}$$ | 第 $$i$$ 个样本的真实目标 | 来自训练数据 |
| $$hat y^{(i)}$$ | 第 $$i$$ 个样本的预测值 | 由模型计算 |
| $$f_{w,b}$$ | 参数为 $$w,b$$ 的预测函数 | 训练后用于预测 |

一个样本可以包含多个特征。因此不能将“一个样本”和“一个特征”混为一谈。

### 3.3 模型的表示（Model Representation）

单变量线性回归：

$$
\hat y=f_{w,b}(x)=wx+b
$$

$$w$$ 是权重或斜率，决定 $$x$$ 改变时预测怎样变化；$$b$$ 是偏置或截距，决定整体上下平移。

例如，设面积单位为百平方米、价格单位为万元，$$w=20,b=10$$，输入 $$x=2$$ 时预测为 $$50$$ 万元。模型参数的数值和单位依赖于特征与目标的计量方式。

完整流程是：**训练数据 → 学习算法寻找参数 → 得到函数 $$f$$ → 将新输入代入函数进行预测**。

### 3.4 总结

线性回归先规定模型形式 $$wx+b$$，再从数据中学习参数。模型形式决定“允许使用什么形状的函数”，代价函数决定“怎样评价这些函数”，优化算法决定“怎样寻找参数”。

## 四、代价函数：如何衡量模型的好坏

### 4.1 理解模型的参数 $$w$$ 和 $$b$$

在 $$f(x)=wx+b$$ 中，$$x$$ 来自样本；$$w,b$$ 是需要学习的参数。改变 $$w$$ 会改变直线倾斜程度，改变 $$b$$ 会改变截距。

$$b$$ 对应 $$x=0$$ 时的模型输出，但这个输出不一定具有实际业务意义。例如训练数据只覆盖正常房屋面积时，不能据此解释“零面积房屋的真实价值”。

**参数**通过训练学习，例如 $$w,b$$；**超参数**控制模型或训练过程，例如学习率、正则化强度，通常通过验证集等方式选择。

### 4.2 定义代价函数 $$J(w,b)$$

**损失函数（loss）**衡量单个样本的预测误差；**代价函数（cost/objective）**把多个样本的损失汇总，形成训练的优化目标。

线性回归采用平方误差：

$$
J(w,b)=\frac{1}{2m}\sum_{i=1}^{m}
\left(f_{w,b}(x^{(i)})-y^{(i)}\right)^2
$$

逐项理解：

1. $$f(x^{(i)})-y^{(i)}$$ 是预测误差。
2. 平方避免正负误差相互抵消，并对较大误差施加更大惩罚。
3. 对所有样本求和，再除以 $$m$$，得到平均误差尺度。
4. 额外的 $$1/2$$ 方便求导，不改变最小值对应的参数。

通常的均方误差 MSE 没有 $$1/2$$，因此这里的 $$J=MSE/2$$。比较不同资料的数值时要先核对定义。

例：两个样本的误差分别为 $$2,-2$$，误差平均值为 $$0$$，但模型并非预测正确；平方误差代价为 $$(4+4)/(2×2)=2$$。

训练目标：

$$
\min_{w,b}J(w,b)
$$

### 4.3 直观理解代价函数

#### 4.3.1 简化情况：$$b=0$$

模型变成 $$f_w(x)=wx$$，只需要选择 $$w$$。每个候选 $$w$$ 对应一条预测直线，也对应一个总体误差 $$J(w)$$。

**模型图的横轴是输入 $$x$$，代价图的横轴是参数 $$w$$**，二者不能混淆。平方误差 $$J(w)$$ 是关于参数的二次函数，通常表现为开口向上的抛物线；最低点对应最佳斜率。

#### 4.3.2 一般情况：$$w$$ 和 $$b$$

同时改变两个参数时，$$J(w,b)$$ 是参数空间中的曲面，平方误差线性回归通常呈“碗”形。曲面高度表示误差，寻找最优参数相当于寻找最低处。

该目标是凸函数，因此没有比全局最优更差的局部极小值。不过，当特征退化或线性相关时，最低点可能不唯一，不能把“凸”直接理解为“一定只有一个最优参数”。

#### 4.3.3 可视化工具：等高线图

**等高线**连接具有相同代价值的参数组合。横纵轴分别为 $$w,b$$，每条曲线代表一个固定的 $$J$$。

接近最低值的等高线围绕最优区域；梯度下降的更新路径可以画在这张图上，用于观察是否缓慢震荡、步长过大或正在收敛。

# 【机器学习02】梯度下降、多维特征线性回归、特征缩放

对应原文件：[第02篇 HTML](<吴恩达机器学习完整笔记/【机器学习02】梯度下降、多维特征线性回归、特征缩放 p10-p21.html>)。

## 一、梯度下降算法

### 1.1 核心思想

**梯度下降（Gradient descent）**是一种迭代优化算法：从当前参数出发，沿代价函数下降的方向小幅移动，重复更新，使代价逐步降低。

**梯度**由各参数的偏导数组成，指向局部上升最快的方向；因此最小化代价时沿负梯度方向更新。它是参数空间中的方向，不是训练数据中某条样本曲线的斜率。

### 1.2 算法详解

#### 1.2.1 更新规则

$$
w\leftarrow w-\alpha\frac{\partial J(w,b)}{\partial w},
\qquad
b\leftarrow b-\alpha\frac{\partial J(w,b)}{\partial b}
$$

$$α>0$$ 是**学习率（learning rate）**，控制每次更新的尺度；偏导数表示当前参数附近，改变某个参数会怎样影响代价。

流程：初始化参数 → 计算当前梯度 → 同步更新参数 → 检查代价和停止条件 → 继续迭代。线性回归可从零初始化；多层神经网络通常需要合适的随机初始化，以打破神经元间的对称性。

#### 1.2.2 重要细节：同步更新

所有梯度都必须基于**同一组旧参数**计算，再一起更新：

```python
dw, db = compute_gradient(X, y, w, b)
w_new = w - alpha * dw
b_new = b - alpha * db
w, b = w_new, b_new
```

不能先修改 $$w$$，再用新 $$w$$ 和旧 $$b$$ 计算 $$b$$ 的梯度；那不再是这里定义的同步梯度下降。

### 1.3 直观理解梯度下降

#### 1.3.1 导数项的作用：指明方向

对单个参数而言，导数为正，减去它会让参数变小；导数为负，减去它会让参数变大。例如 $$J(w)=(w-3)^2$$，在 $$w=5$$ 处导数为 $$4$$，更新会朝 $$3$$ 移动。

导数绝对值还影响更新幅度。靠近光滑极小值时梯度往往变小，所以即使学习率不变，实际更新也会自然缩小。

#### 1.3.2 学习率 $$α$$ 的作用：决定步长

- $$α$$ 太小：每次移动太少，收敛缓慢。
- $$α$$ 合适：能够较快接近低代价区域。
- $$α$$ 太大：可能跨过最低点，震荡甚至发散。

参数的实际变化是 $$α×梯度$$，所以不能脱离特征尺度和梯度大小单独评价学习率。

### 1.4 梯度下降的特性

梯度下降在一般非凸目标上可能收敛到不同区域，其结果受初始化、学习率等因素影响。神经网络训练还可能遇到鞍点、平坦区域等现象。

在最低点梯度为零时，更新停止；但梯度为零不一定意味着全局最优。固定学习率也不能保证任何问题上每步代价都下降，这需要合适的步长与目标条件。

### 1.5 梯度下降用于线性回归

#### 1.5.1 线性回归的梯度

令 $$e^{(i)}=wx^{(i)}+b-y^{(i)}$$，则：

$$
\frac{\partial J}{\partial w}
=\frac1m\sum_{i=1}^m e^{(i)}x^{(i)},
\qquad
\frac{\partial J}{\partial b}
=\frac1m\sum_{i=1}^m e^{(i)}
$$

$$w$$ 的梯度是“误差乘输入”的平均值，$$b$$ 的梯度是误差平均值。因为所有样本都要参与计算，不能只根据一个样本的误差决定整批参数的变化。

#### 1.5.2 凸函数与全局最优解

线性回归配合平方误差构成凸优化问题。在适当步长等条件下，梯度下降可以接近全局最小代价。若设计矩阵不满秩，多个参数组合可能给出相同的最小代价。

### 1.6 “批”梯度下降

**批梯度下降（Batch GD）**每一步使用完整训练集。与它对比：

| 方法 | 每次使用的数据 | 特点 |
|---|---|---|
| Batch GD | 全部 $$m$$ 个样本 | 梯度稳定，单次计算可能较重 |
| 随机梯度下降 SGD | 一个样本 | 更新频繁，波动较大 |
| Mini-batch GD | 一小批样本 | 兼顾计算效率与梯度估计，常用于神经网络 |

**一次参数更新**与**一个 epoch**不同：epoch 表示把训练数据完整遍历一遍，小批量训练中通常包含多次参数更新。

## 二、多维特征的线性回归

### 2.1 新的符号表示

一个房屋可由面积、卧室数、楼层数、房龄共同描述，此时 $$n=4$$。

- $$x_j$$：某个样本的第 $$j$$ 个特征。
- $$x^{(i)}$$：第 $$i$$ 个样本的完整特征向量。
- $$x_j^{(i)}$$：第 $$i$$ 个样本的第 $$j$$ 个特征。

训练集矩阵 $$X$$ 的形状通常为 $$(m,n)$$：每一行是一个样本，每一列是一个特征。

### 2.2 多维特征的模型表示

$$
f_{\mathbf w,b}(\mathbf x)=w_1x_1+w_2x_2+\cdots+w_nx_n+b
$$

每个特征有对应权重。例如房龄权重可能为负，表示在其他输入固定时，房龄增大会降低预测价格。这是模型的条件关系，不能直接当成因果结论。

#### 2.2.1 向量化表示

$$
f_{\mathbf w,b}(\mathbf x)=\mathbf w^\top\mathbf x+b,
\qquad
\hat{\mathbf y}=X\mathbf w+b
$$

这里 $$w,x$$ 都有 $$n$$ 个元素，点积得到一个标量；对 $$m$$ 个样本一次计算，得到长度为 $$m$$ 的预测向量。NumPy 中标量 $$b$$ 通过广播加到每个预测上。

### 2.3 向量化的威力

**向量化（Vectorization）**把逐元素循环表达为数组运算，使底层数值库能够批量计算。它改变的是计算实现方式，通常不改变所表示的数学模型。

```python
import numpy as np

x = np.array([2.0, 3.0, 10.0])
w = np.array([20.0, 1.0, -0.5])
b = 8.0
prediction = np.dot(x, w) + b  # 46.0
```

正确性首先取决于形状与含义是否一致。矩阵维度恰好能够相乘，并不自动意味着样本轴与特征轴放对了。

### 2.4 多维特征的梯度下降

对每个特征权重：

$$
w_j\leftarrow w_j-\alpha\frac1m
\sum_{i=1}^m(f(\mathbf x^{(i)})-y^{(i)})x_j^{(i)}
$$

偏置仍按平均误差更新。矩阵形式为：

$$
\mathbf e=X\mathbf w+b-\mathbf y,\quad
\nabla_{\mathbf w}J=\frac1mX^\top\mathbf e,\quad
\frac{\partial J}{\partial b}=\frac1m\sum_i e_i
$$

其中 $$X.T @ e$$ 的形状为 $$(n,)$$，正好对应 $$n$$ 个权重。

### 2.5 正规方程——选学

**正规方程（Normal equation）**通过求解最小二乘问题直接获得线性回归参数，不需要选学习率或反复做梯度更新。

令 $$\tilde X$$ 为增加常数列的设计矩阵、$$\theta$$ 包含偏置与权重，在满列秩条件下：

$$
\theta=(\tilde X^\top\tilde X)^{-1}\tilde X^\top y
$$

此式用于理解原理。实际计算更宜使用 $$np.linalg.lstsq$$ 等数值求解器，避免手动求逆；矩阵不满秩时，上面的普通逆可能不存在。大规模问题中，迭代方法可能更合适。

## 三、特征缩放

### 3.1 为什么需要特征缩放？

**特征缩放（Feature scaling）**把不同特征调整到相近的数值尺度。比如面积在上千，卧室数只有几个，参数空间中的等高线可能很狭长，梯度下降因此左右震荡、沿谷底前进缓慢。

缩放有助于改善优化的数值条件。它不是简单地让所有权重相等，也不能仅凭输入数值的比例断言两个梯度必然有同样比例。

### 3.2 特征缩放的目标

让各特征的典型取值范围或波动程度接近，使同一个学习率更容易适用于不同参数。无需强求所有数据严格落在同一个区间，更不要求所有特征服从正态分布。

### 3.3 特征缩放的方法

#### 3.3.1 最大值归一化（Max Scaling）

$$
x'=\frac{x}{x_{\max}}
$$

例如正面积特征最大值为 $$2000$$，面积 $$1000$$ 缩放后为 $$0.5$$。这是原文的最大值缩放，与 $$(x-min)/(max-min)$$ 的 Min-Max 缩放是不同公式。

当数据有负值、最大值为零或异常极端值时，要检查这种处理是否合适，不能机械套用。

#### 3.3.2 均值归一化（Mean Normalization）

$$
x'=\frac{x-\mu}{x_{\max}-x_{\min}}
$$

先减去该特征的训练集均值，再除以范围。假设最大 $$2000$$、最小 $$500$$、均值 $$1000$$，则 $$x=1750$$ 变为 $$0.5$$。

#### 3.3.3 Z-score 标准化

$$
x'=\frac{x-\mu}{\sigma}
$$

$$μ$$ 是训练集均值，$$σ$$ 是训练集标准差。处理后特征通常具有接近零的均值、单位标准差；这不会自动把偏斜数据变成高斯分布。

### 3.4 特征缩放的经验法则

在**训练集上计算**均值、标准差、最大最小值，再把同一套参数用于验证集、测试集和新输入。若使用测试集统计量，会使测试信息泄漏到模型流程。

常数特征可能导致分母为零，要删除或特殊处理。线性模型、神经网络、距离方法通常受尺度影响较大；常规决策树按特征阈值分裂，通常没有相同的缩放需求。

# 【机器学习03】学习率与特征工程、多项式回归、逻辑回归

对应原文件：[第03篇 HTML](<吴恩达机器学习完整笔记/【机器学习03】学习率与特征工程、多项式回归、逻辑回归 p21-p31.html>)。

## 一、线性回归的实践技巧

### 1.1 调试梯度下降

训练时记录代价，观察它随迭代的变化，可以帮助判断代码、学习率和停止条件是否合理。只看最后一个代价值，很难发现中间震荡或发散。

#### 1.1.1 学习曲线

此处的学习曲线以**迭代次数为横轴、训练代价为纵轴**。在标准批梯度下降且步长合适时，代价应总体下降，之后逐渐趋于平稳。

代价不断增大，要检查梯度符号、公式、同步更新与学习率；代价下降极慢，要检查缩放与步长；出现 $$NaN$$，还要检查溢出、非法除法或对数。

第08篇还有“误差随训练样本数量变化”的学习曲线，二者横轴不同，诊断目的也不同。Mini-batch 的单批损失出现波动通常是正常现象。

#### 1.1.2 如何选择学习率 $$α$$

可以按近似几何间隔试验，例如 $$0.001,0.003,0.01,0.03,0.1$$，比较代价变化和收敛速度。

先确保较小学习率下能正常降低代价，再尝试增大。小学习率仍无法下降时，应优先怀疑实现或数据问题，不能只反复调参。

### 1.2 特征工程

**特征工程（Feature engineering）**：根据任务知识，把已有输入转换、组合成更有利于模型学习的表示。

例如房屋占地的宽和深单独与价格关系不够直接，可以构造 $$面积=宽×深$$。这个新特征使简单线性模型能够表达原始输入中的乘积关系。

特征工程包括构造比例、交互项、时间属性、对数变换等。构造过程不能使用预测时无法获得的信息，否则离线效果可能很好，上线却不可用。

### 1.3 多项式回归

**多项式回归（Polynomial regression）**把 $$x²,x³$$ 等作为新特征，再使用线性回归：

$$
f(x)=w_1x+w_2x^2+w_3x^3+b
$$

曲线对原始输入 $$x$$ 可以是非线性的，但对待学习参数 $$w$$ 仍是线性的，因此属于线性回归模型。也可以使用 $$\sqrt{x}$$ 等其他非线性特征。

选择高次项能提高表达能力，也可能造成过拟合。新增多项式特征后要重新考虑缩放：若 $$x$$ 在 $$1～1000$$，$$x³$$ 可达到 $$10^9$$。

## 二、逻辑回归与分类问题

### 2.1 什么是分类问题

分类要判断输入属于哪个类别。二分类常设 $$y∈{0,1}$$，并约定 $$1$$ 表示关注的正类，例如恶性、欺诈或垃圾邮件。

正类是建模约定，不代表价值上的“好”。后续的精确率、召回率都依赖这个约定。

#### 2.1.1 线性回归用于分类的局限

普通线性回归输出不受 $$[0,1]$$ 限制，不便直接解释为概率；平方误差拟合数值的目标，也不完全对应分类需求。个别远处样本可能显著拉动直线，改变阈值对应的位置。

线性回归并非绝对不能用于二值标签，但逻辑回归提供了更适合二分类的概率模型与损失函数。

### 2.2 逻辑回归模型

#### 2.2.1 Sigmoid 函数

$$
g(z)=\frac1{1+e^{-z}}
$$

Sigmoid 将任意实数映射到 $$(0,1)$$。$$z=0$$ 时输出 $$0.5$$；$$z$$ 很大时接近 $$1$$，很小时接近 $$0$$。

它是平滑的 S 形函数，不能与“输出直接为 0 或 1 的硬阈值函数”混同。

#### 2.2.2 模型表示与解读

$$
z=\mathbf w^\top\mathbf x+b,\qquad
f_{\mathbf w,b}(\mathbf x)=g(z)
=P(y=1\mid\mathbf x;\mathbf w,b)
$$

若输出 $$0.8$$，表示模型估计当前输入属于正类的概率为 $$80%$$，不是“类别等于 0.8”。概率解释的可靠程度还取决于数据、训练和校准质量。

逻辑回归虽然名字中有“回归”，在本课程中用于**分类**。

### 2.3 决策边界

**决策边界（Decision boundary）**是特征空间中预测类别发生变化的位置。

#### 2.3.1 线性决策边界

当阈值为 $$0.5$$ 时，$$g(z)≥0.5$$ 等价于 $$z≥0$$，所以边界为：

$$
\mathbf w^\top\mathbf x+b=0
$$

两特征时是一条直线，多特征时是超平面。例如 $$z=x_1+x_2-3$$，边界为 $$x_1+x_2=3$$。

#### 2.3.2 非线性决策边界

在逻辑回归中加入平方项等特征，就可以得到关于原始输入的非线性边界。例如：

$$
z=x_1^2+x_2^2-1
$$

阈值 $$0.5$$ 对应单位圆边界，圆内外预测不同类别。这里的非线性来自特征映射，而不是简单地说“用了 Sigmoid，边界就一定弯曲”。

若阈值为 $$t$$，边界满足 $$z=\log(t/(1-t))$$；改变分类阈值也会改变决策区域。

## 三、逻辑回归的代价函数

### 3.1 平方误差代价函数的局限性

把 Sigmoid 输出代入平方误差后，目标对参数一般不再是凸函数，优化可能更困难。逻辑回归采用与 Bernoulli 概率模型匹配的对数损失。

需要区分：**线性回归加平方误差**是凸问题；**线性 logits 的逻辑回归加标准交叉熵**也是凸问题；多层神经网络的交叉熵训练通常不是凸问题。

### 3.2 逻辑损失函数

#### 3.2.1 当 $$y=1$$ 时

$$
L(f,y)=-\log f
$$

预测 $$f$$ 接近 $$1$$ 时损失小，接近 $$0$$ 时损失大。模型若非常自信地把正样本判断为负类，会受到较重惩罚。

#### 3.2.2 当 $$y=0$$ 时

$$
L(f,y)=-\log(1-f)
$$

预测越接近 $$0$$ 越好；越接近 $$1$$，损失越大。例如同一正样本，预测 $$0.9$$ 的损失约 $$0.105$$，预测 $$0.1$$ 的损失约 $$2.303$$。

### 3.3 代价函数与梯度下降

#### 3.3.1 简化版代价函数

把两种标签合并，得到**二元交叉熵（Binary cross-entropy）**：

$$
L(f,y)=-y\log f-(1-y)\log(1-f)
$$

整个训练集的代价：

$$
J(\mathbf w,b)=-\frac1m\sum_{i=1}^m
\left[y^{(i)}\log f(\mathbf x^{(i)})
+(1-y^{(i)})\log(1-f(\mathbf x^{(i)}))\right]
$$

当 $$y=1$$，第二项消失；当 $$y=0$$，第一项消失。实现时通常使用框架提供的稳定交叉熵，避免手算 $$log(0)$$。

#### 3.3.2 逻辑回归的梯度下降

$$
w_j\leftarrow w_j-\frac{\alpha}{m}
\sum_i(f(\mathbf x^{(i)})-y^{(i)})x_j^{(i)},
\qquad
b\leftarrow b-\frac{\alpha}{m}\sum_i(f(\mathbf x^{(i)})-y^{(i)})
$$

形式与线性回归相似，但这里的 $$f$$ 是 **Sigmoid 概率输出**，不是线性函数本身。公式外形相同，不表示两个模型及其损失相同。

# 【机器学习04】过拟合与欠拟合、正则化

对应原文件：[第04篇 HTML](<吴恩达机器学习完整笔记/【机器学习04】过拟合与欠拟合、正则化 p32-p37.html>)。

## 一、过拟合问题

### 1.1 欠拟合、适度拟合与过拟合

**泛化（Generalization）**是模型在未参与训练的新数据上保持良好表现的能力。训练误差小，只说明模型拟合了训练数据，不能单独证明泛化好。

| 状态 | 含义 | 常见表现 |
|---|---|---|
| 欠拟合（Underfitting） | 模型未充分学到数据规律 | 训练误差高，验证误差也高 |
| 适度拟合 | 学到了可推广的主要规律 | 训练与验证表现均较好 |
| 过拟合（Overfitting） | 学到了训练集中特有的噪声或偶然细节 | 训练误差低，验证误差明显较高 |

课程常用**高偏差**描述欠拟合倾向、**高方差**描述对训练数据变化敏感的过拟合倾向。它们是诊断语言，不能只根据模型外观下定论。

#### 1.1.1 回归中的例子

真实房价随面积呈弯曲趋势时，直线可能过于简单，出现欠拟合；适度的多项式能描述趋势；过高次多项式可能在训练点间剧烈摆动，把噪声也拟合进去。

不是次数越高越差，而是复杂度要与样本数量、噪声、正则化共同考虑。

#### 1.1.2 分类中的例子

用直线分隔本来需要曲线分开的类别，可能欠拟合；过于曲折的边界围住少数特殊训练点，可能过拟合。判断仍应结合训练集与验证集误差。

### 1.2 如何解决过拟合

1. **增加具有代表性的训练数据**：帮助模型区分共同规律与偶然噪声。
2. **减少或选择特征、降低模型复杂度**：去掉不必要的自由度。
3. **正则化**：保留较丰富的模型结构，同时约束参数或解的复杂度。

数据应与目标任务匹配；重复复制同一批样本不会产生同等数量的新信息。减少特征也可能删掉有效信息，因此要用验证效果判断。

## 二、正则化

### 2.1 正则化的直觉

**正则化（Regularization）**是在训练目标或训练过程里加入约束，抑制过度复杂的拟合，改善泛化。

以多项式回归为例，不一定删除高次项，也可以惩罚其大权重，让模型更难利用高次项形成剧烈弯曲。课程重点是 **L2 正则化**：惩罚权重平方和。

L2 倾向于缩小权重，但通常不会把它们精确变为零；不要与强调稀疏解的 L1 正则化混淆。

### 2.2 正则化的实现：修改代价函数

$$
J_{\mathrm{reg}}(\mathbf w,b)
=J_{\mathrm{data}}(\mathbf w,b)
+\frac{\lambda}{2m}\sum_{j=1}^n w_j^2
$$

第一项要求拟合训练数据，第二项惩罚过大的权重。通常不惩罚偏置 $$b$$，因为偏置主要控制整体基线，而不是各特征的变化敏感程度。

使用前应关注特征尺度：相同预测关系在不同尺度下可能对应不同权重大小，L2 对这些权重的惩罚也会改变。

#### 2.2.1 正则化参数 $$λ$$

$$λ$$ 控制拟合数据与缩小参数之间的权衡：

- $$λ=0$$：没有该正则化项。
- $$λ$$ 太小：可能无法有效抑制过拟合。
- $$λ$$ 太大：权重被压得过小，模型可能欠拟合。

$$λ$$ 是超参数，通过验证集选择。不能把测试集反复用于调节 $$λ$$，否则测试评估会受到选择过程影响。

### 2.3 正则化在线性回归中的应用

$$
J(\mathbf w,b)=\frac1{2m}\sum_i(f(\mathbf x^{(i)})-y^{(i)})^2
+\frac{\lambda}{2m}\sum_jw_j^2
$$

对于高度相关的特征，正则化也有助于约束不稳定的权重解。较小权重并不天然等于较小预测误差，最终目标仍是新数据表现。

#### 2.3.1 梯度下降更新规则

$$
w_j\leftarrow w_j-\alpha\left[
\frac1m\sum_i(f(\mathbf x^{(i)})-y^{(i)})x_j^{(i)}
+\frac{\lambda}{m}w_j\right]
$$

也可以写成：

$$
w_j\leftarrow
\left(1-\frac{\alpha\lambda}{m}\right)w_j
-\frac{\alpha}{m}\sum_i(f(\mathbf x^{(i)})-y^{(i)})x_j^{(i)}
$$

在合适步长下，可理解为每次先缩小一点权重，再按照数据梯度调整。偏置更新不增加 $$λb/m$$。

### 2.4 正则化在逻辑回归中的应用

#### 2.4.1 代价函数

$$
J(\mathbf w,b)=
-\frac1m\sum_i\left[y^{(i)}\log f_i+(1-y^{(i)})\log(1-f_i)\right]
+\frac{\lambda}{2m}\sum_jw_j^2
$$

其中 $$f_i=g(\mathbf w^\top\mathbf x^{(i)}+b)$$。正则化能抑制过大的参数与过度自信的复杂拟合，但不能替代正确的数据划分与质量检查。

#### 2.4.2 梯度下降更新规则

更新形式与上面的正则化线性回归相同，只需使用逻辑回归的 $$f_i$$。记忆时抓住：**原来的数据梯度，加上 $$λw_j/m$$；偏置通常不加惩罚**。

不同框架的损失平均方式和 L2 系数定义可能不同，迁移公式时应核对 $$m$$、$$1/2$$ 与系数位置，不能只按参数名称照搬。

# 【机器学习05】神经网络、模型表示、前向传播、TensorFlow 实现

对应原文件：[第05篇 HTML](<吴恩达机器学习完整笔记/【机器学习05】神经网络、模型表示、前向传播、TensorFlow实现 p38-p46.html>)。

## 一、神经网络简介

### 1.1 什么是神经网络

**神经网络（Neural network，NN）**是由多个可学习的计算单元连接而成的模型。每个单元接收数值输入，计算加权和与偏置，再通过激活函数输出结果；多个单元组成层，多层依次连接形成网络。

它受到生物神经元的启发，但人工神经元只是数学抽象，不能直接等同于真实大脑的工作机制。

与手动指定少量特征的简单模型相比，神经网络能够同时学习中间特征表示与最终预测关系。网络的表达能力取决于层数、每层单元数、连接方式及激活函数等。

### 1.2 神经网络为何现在如此强大？

原文强调两项推动因素：**更多可用数据**与**更强计算能力**。大量数据让复杂模型有机会学到可推广的规律，GPU 等硬件使大规模矩阵计算和训练成为可能。

数据、模型规模、优化方法需要配合。不能把这理解成“网络越大必然越好”：数据质量不足、训练不充分或任务不匹配时，增加规模也未必改善效果。

## 二、神经网络的模型表示

### 2.1 单个神经元：逻辑回归单元

一个采用 Sigmoid 的神经元：

$$
z=\mathbf w^\top\mathbf x+b,\qquad a=g(z)
$$

$$z$$ 是**预激活值**，$$a$$ 是**激活值（activation）**。当这个单元用作二分类输出时，可以把 $$a$$ 解释为正类概率。

隐藏层的激活值通常是中间特征，不一定具有概率含义。神经元也可以使用 ReLU、线性等其他激活，不能把所有神经元都定义为逻辑回归。

### 2.2 构建网络：层

| 层 | 作用 | 是否通常计入网络的可学习层数 |
|---|---|---|
| 输入层 | 接收原始特征，记为 $$a^{[0]}=x$$ | 通常不计 |
| 隐藏层 | 计算中间特征表示 | 计入 |
| 输出层 | 产生任务所需的预测 | 计入 |

**全连接层（Dense/Fully connected layer）**中，每个神经元都接收前一层的所有输出。网络的层数、每层单元数和连接关系合称**网络架构（architecture）**。

例如 $$2→3→1$$ 表示两个输入特征、一个含三个单元的隐藏层、一个输出单元。每层神经元有各自独立的参数，不能共用一组权重后期待它们自动学出不同功能。

### 2.3 神经网络如何自动学习特征

在人脸识别的直观解释中，较浅层可能提取边缘与局部变化，中间层组合成局部结构，更深层形成有利于身份判断的表示。

这里的“可能”很重要：某个神经元未必清晰对应“眼睛”“鼻子”或“性价比”，很多表示由多个单元共同编码。中间特征通过最终任务的损失反向优化，不需要为每个隐藏单元提供单独标签。

## 三、前向传播

**前向传播（Forward propagation）**是从输入开始，按照网络连接顺序逐层计算，直到得到输出的过程。它执行预测；训练还需要损失计算、反向传播和参数更新。

### 3.1 逐层计算详解

以 $$2→3→1$$ 为例：

1. 将两个输入特征分别送给第一层的三个神经元。
2. 三个神经元各自进行加权求和与激活，组成三维向量 $$a^{[1]}$$。
3. 输出神经元接收完整的 $$a^{[1]}$$，计算 $$a^{[2]}$$。
4. 若是二分类概率输出，可根据阈值生成最终类别。

每个神经元接收的是上一层的**完整向量**，不是只接收与自己编号相同的一个激活值。

### 3.2 更复杂的网络与数学符号

$$
z_j^{[l]}=(\mathbf w_j^{[l]})^\top\mathbf a^{[l-1]}+b_j^{[l]},
\qquad
a_j^{[l]}=g^{[l]}(z_j^{[l]})
$$

| 符号部分 | 含义 |
|---|---|
| $$[l]$$ | 第 $$l$$ 层，方括号不是指数 |
| 下标 $$j$$ | 该层第 $$j$$ 个神经元 |
| $$w_j^{[l]}$$ | 连接上一层到该神经元的权重向量 |
| $$b_j^{[l]}$$ | 该神经元的偏置 |
| $$a^{[l-1]}$$ | 上一层的全部激活值 |

例如 $$a_2^{[3]}$$ 是第3层第2个单元的输出，使用第3层该单元的参数和第2层的激活向量计算。

### 3.3 完整示例：手写数字识别

原文的“0/1”识别网络：

| 阶段 | 输入/输出维度 | 含义 |
|---|---|---|
| 输入 | 64 | $$8×8$$ 灰度图展开成向量 |
| 隐藏层1 | $$64→25$$ | 提取第一组中间特征 |
| 隐藏层2 | $$25→15$$ | 进一步组合特征 |
| 输出层 | $$15→1$$ | 输出“数字为1”的概率 |

前向计算为 $$x→a^{[1]}→a^{[2]}→a^{[3]}$$。若任务改为识别 0～9 十类，通常改为十个输出分数并使用 Softmax，而不是仍用单个二分类概率。

### 3.4 神经网络的应用实例

咖啡烘焙中，以温度与时长为输入、是否合格为标签。合格区域可能同时受“温度过高”“时间过短”等因素约束，多个隐藏单元可以组合成复杂决策区域。

图像识别、语音、文本等问题也可以用神经网络，但通常会根据数据结构选择相应架构，而不总是简单展开后使用 Dense。

## 一、构建与训练神经网络：TensorFlow 实践

### 1.1 使用 Keras Sequential API 搭建网络

**Sequential**用于按顺序堆叠网络层，每层输出作为下一层输入。原文咖啡模型包含一个三单元隐藏层和一个二分类输出层。

```python
import numpy as np
import tensorflow as tf

def train_coffee_model(X_train, y_train, X_new):
    X_train = np.asarray(X_train, dtype=np.float32)
    y_train = np.asarray(y_train, dtype=np.float32).reshape(-1, 1)
    X_new = np.asarray(X_new, dtype=np.float32).reshape(-1, 2)
    normalizer = tf.keras.layers.Normalization(axis=-1)
    normalizer.adapt(X_train)
    model = tf.keras.Sequential([
        tf.keras.Input(shape=(2,)),
        normalizer,
        tf.keras.layers.Dense(3, activation="sigmoid"),
        tf.keras.layers.Dense(1, activation="sigmoid"),
    ])
    model.compile(
        optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
        loss=tf.keras.losses.BinaryCrossentropy(),
    )
    history = model.fit(X_train, y_train, epochs=100, verbose=0)
    probabilities = model.predict(X_new, verbose=0)
    return model, history, probabilities
```

代码中的训练轮数和学习率仅为示例。归一化层只用训练输入 $$adapt$$，随后由模型对新输入采用同样变换。

四个动作应分清：

- **创建模型**：定义前向函数及参数结构。
- **compile**：配置损失函数、优化器等训练规则。
- **fit**：使用数据计算梯度并更新参数。
- **predict**：使用已有参数做前向预测。

未训练网络也能输出数值，但这些值来自初始化参数，不代表学会了任务。

### 1.2 [附录] 手动实现前向传播的底层逻辑

为理解 Dense，约定权重矩阵的**每一列对应一个输出神经元**。若输入有 $$d$$ 维、输出有 $$u$$ 个神经元，$$W.shape=(d,u)$$、$$b.shape=(u,)$$。

```python
import numpy as np

def sigmoid(z):
    z = np.asarray(z, dtype=float)
    return np.exp(-np.logaddexp(0.0, -z))

def dense_loop(a_in, W, b):
    units = W.shape[1]
    a_out = np.zeros(units)
    for j in range(units):
        z = np.dot(a_in, W[:, j]) + b[j]
        a_out[j] = sigmoid(z)
    return a_out

def forward_two_layers(x, W1, b1, W2, b2):
    a1 = dense_loop(x, W1, b1)
    return dense_loop(a1, W2, b2)
```

该代码计算已有参数下的输出，没有实现训练。Sigmoid 写成等价的稳定形式，避免大幅输入造成不必要的指数溢出。

## 三、性能优化与训练流程再探

### 3.1 向量化：从 For 循环到矩阵乘法

延续“权重按列存放”的约定，一批输入 $$A$$ 有形状 $$(m,d)$$：

$$
Z=AW+b,\qquad A_{\mathrm{out}}=g(Z)
$$

$$W$$ 为 $$(d,u)$$，结果 $$Z$$ 为 $$(m,u)$$。偏置 $$(u,)$$ 被广播到每个样本。

```python
def dense_vectorized(A, W, b):
    return sigmoid(A @ W + b)
```

| 操作 | 含义 |
|---|---|
| $$A @ W$$、$$np.matmul(A,W)$$ | 矩阵乘法，包含乘积与求和 |
| $$A * B$$ | 按广播规则逐元素相乘 |
| $$A.T$$ | 二维矩阵转置，交换行列 |

不同教材也可能把神经元权重按行存放，写成 $$W @ a+b$$。两种约定都可以，必须同时核对输入布局、权重形状及转置，不能把公式混用。

### 3.2 神经网络的训练流程

一次训练更新包含：

1. **前向传播**：由输入计算预测。
2. **计算损失**：比较预测与真实标签，必要时加入正则项。
3. **反向传播**：利用链式法则，计算损失对各层参数的梯度。
4. **优化器更新**：按 SGD、Adam 等规则修改参数。

这四步在许多 mini-batch 和多个 epoch 上重复。**反向传播负责求梯度，优化器负责使用梯度更新参数**，二者职责不同。回归常用平方误差，二分类常用二元交叉熵，损失必须与输出含义配套。

# 【机器学习07】激活函数、Softmax 多分类与优化器

对应原文件：[第07篇 HTML](<吴恩达机器学习完整笔记/【机器学习07】 激活函数精讲、Softmax多分类与优化器进阶 p57-69.html>)。

## 一、激活函数

### 1.1 激活函数的作用：需求预测实例

**激活函数（Activation function）**把神经元的加权输入 $$z$$ 转换为激活值 $$a=g(z)$$。它决定输出范围，也为网络引入非线性表达能力。

需求预测中，某个隐藏特征可能在价格足够低时才明显影响销量。非线性激活允许网络表示“达到条件才触发”“不同区间不同响应”等关系。

### 1.2 常见激活函数

| 函数 | 公式 | 输出范围 | 关键特性 |
|---|---|---|---|
| Sigmoid | $$1/(1+e^{-z})$$ | $$(0,1)$$ | 适合二分类概率输出；两端容易饱和 |
| ReLU | $$max(0,z)$$ | $$[0,+∞)$$ | 正半轴梯度为1，计算简单，常用于隐藏层 |
| 线性 | $$g(z)=z$$ | 实数 | 不限制输出范围，常用于回归或 logits |

**饱和**指输入进入某些区域后，函数变化很小、导数接近零，梯度传递可能变弱。ReLU 负半轴导数为零，也可能出现单元长期不激活的情况。

### 1.3 如何为网络的每一层选择激活函数

#### 1.3.1 输出层的选择

| 任务 | 常见输出设置 | 常见损失 |
|---|---|---|
| 二分类 | 单个 Sigmoid 概率，或单个线性 logit | 二元交叉熵 |
| 单标签多分类 | $$C$$ 个 Softmax 概率，或 $$C$$ 个线性 logits | 多分类交叉熵 |
| 多标签分类 | $$C$$ 个独立 Sigmoid 概率，或对应 logits | 各标签二元交叉熵 |
| 任意实数回归 | 线性输出 | MSE 等回归损失 |
| 非负数回归 | 可考虑 ReLU 等非负输出 | 与任务匹配的回归损失 |

非负输出只是建模选择之一，不能仅凭目标非负就断言 ReLU 永远最佳。输出范围、梯度和业务需求应一起考虑。

#### 1.3.2 隐藏层的选择

课程通常推荐从 ReLU 开始尝试。相比 Sigmoid，它在正区间不会因输入变大而饱和，往往更便于训练较深网络。

隐藏层选择并非普遍定律，实际还会使用其他激活。关键是保留适当非线性，避免无意中把整个网络变成一个线性映射。

### 1.4 选择策略总结与 TensorFlow 代码实践

先根据任务确定**输出层与损失的组合**，再选择隐藏层。以销量回归为例，可以使用 $$Dense(25,activation="relu")$$ 等隐藏层和 $$Dense(1)$$ 线性输出；二分类则配二元交叉熵。

$$Dense(1)$$ 默认线性输出，不能直接把这个原始数值当作概率。若使用 logits 训练，在展示概率时需要额外转换。

### 1.5 非线性激活函数的必要性

假设两层都为线性：

$$
a^{[1]}=W_1x+b_1,\quad
a^{[2]}=W_2a^{[1]}+b_2
=(W_2W_1)x+(W_2b_1+b_2)
$$

无论堆叠多少层，整体仍是一个仿射映射。**增加线性层的数量本身不能获得通常期待的非线性表达能力**。中间线性层可用于特定结构设计，但不能代替网络所需的非线性。

## 二、Softmax 回归与多分类

### 2.1 多分类问题

**单标签多分类**：每个输入从 $$C$$ 个互斥类别中选择一个，例如数字识别。标签可以是整数 $$0～C-1$$，也可以是对应的 one-hot 向量。

这与“一张图中同时有汽车和行人”的多标签问题不同，后者允许多个标签同时为真。

### 2.2 Softmax 回归原理

先为每个类别计算分数 $$z_j$$，这些未归一化分数叫 **logits**：

$$
p_j=\frac{e^{z_j}}{\sum_{k=1}^{C}e^{z_k}}
$$

所有 $$p_j$$ 非负且总和为 $$1$$，可解释为互斥类别的预测分布。预测类别通常取 $$argmax_j p_j$$。

例如 logits $$[1,2,3]$$ 对应概率约 $$[0.0900,0.2447,0.6652]$$，最大概率对应第3个类别。Logit 本身不要求在 $$[0,1]$$，也不要求相加为1。

### 2.3 Softmax 的损失函数：交叉熵

真实类别为 $$c$$ 时，单样本损失：

$$
L=-\log p_c
$$

使用 one-hot 标签：

$$
L=-\sum_{j=1}^{C}y_j\log p_j
$$

因为只有真实类别处的 $$y_j=1$$，两种写法等价。给真实类别的概率越小，损失越大。多个样本通常对损失求平均。

### 2.4 将 Softmax 集成到神经网络

隐藏层负责学习表示，最后输出 $$C$$ 个 logits，再通过 Softmax 转成概率。网络可以是 $$输入→ReLU隐藏层→C个线性输出$$。

Softmax 不仅属于“单层 Softmax 回归”，也可以作为深层网络的最终概率变换。增加隐藏层后，整个目标通常不再是凸优化问题。

## 三、TensorFlow 实现与数值稳定性

### 3.1 一个有风险的初步实现

先显式计算 Softmax，再对概率取对数，数学上没有问题；但极端分数可能产生指数溢出、概率下溢或舍入成零。

$$Dense(C,activation="softmax")$$ 配合概率模式的多分类交叉熵是有效组合，不能把它说成一定错误。原文强调的是：交由稳定的 logits 损失统一计算，通常更稳妥。

### 3.2 数值舍入误差

计算机浮点数精度有限。例如很大的负 logit 转为概率后可能下溢为零，随后 $$log(0)$$ 变为负无穷。

Softmax 可以利用平移不变性：

$$
p_j=\frac{e^{z_j-M}}{\sum_ke^{z_k-M}},
\qquad M=\max_k z_k
$$

减去最大值不改变概率，却能避免指数项向正无穷溢出。稳定交叉熵还会利用 log-sum-exp 等等价计算。

### 3.3 使用 $$from_logits=True$$ 提升数值稳定性

$$from_logits=True$$ 表示**损失函数接收原始 logits**。因此输出层使用线性输出，不能先手工 Sigmoid/Softmax 后又把概率当 logits 传入。

| 模型输出 | 损失设置 |
|---|---|
| 单个线性 logit | $$BinaryCrossentropy(from_logits=True)$$ |
| 单个 Sigmoid 概率 | $$BinaryCrossentropy(from_logits=False)$$ |
| $$C$$ 个线性 logits、整数标签 | $$SparseCategoricalCrossentropy(from_logits=True)$$ |
| $$C$$ 个线性 logits、one-hot 标签 | $$CategoricalCrossentropy(from_logits=True)$$ |

### 3.4 最终推荐的代码实现

```python
import tensorflow as tf

def build_digit_classifier():
    model = tf.keras.Sequential([
        tf.keras.Input(shape=(64,)),
        tf.keras.layers.Dense(25, activation="relu"),
        tf.keras.layers.Dense(15, activation="relu"),
        tf.keras.layers.Dense(10),
    ])
    model.compile(
        optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
        loss=tf.keras.losses.SparseCategoricalCrossentropy(
            from_logits=True
        ),
        metrics=["accuracy"],
    )
    return model

def predict_digit(model, X_new):
    logits = model(X_new, training=False)
    probabilities = tf.nn.softmax(logits, axis=-1)
    classes = tf.argmax(logits, axis=-1)
    return probabilities, classes
```

训练标签应是 $$0～9$$ 的整数。只要类别最大值，直接对 logits 取 $$argmax$$ 即可；需要概率展示时才做 Softmax。

## 四、扩展主题

### 4.1 多标签分类

**多标签分类（Multi-label classification）**允许一个样本同时属于多个类别。图像可同时含汽车、公交车和行人，目标可以写为 $$[1,0,1]$$。

每个标签是独立的二分类输出，通常用多个 Sigmoid 和逐标签二元交叉熵，各输出概率不要求相加为1。Softmax 的互斥约束不适合直接表达这种目标。

### 4.2 Adam 优化算法

**Adam**利用梯度的一阶矩与二阶矩估计，为不同参数自适应调整更新。设当前梯度为 $$g_t$$：

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\qquad
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2
$$

偏差修正后：

$$
\hat m_t=\frac{m_t}{1-\beta_1^t},\quad
\hat v_t=\frac{v_t}{1-\beta_2^t},\quad
\theta_t=\theta_{t-1}
-\alpha\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}
$$

平方、开方与除法按元素进行。$$m_t$$ 平滑梯度方向，$$v_t$$ 跟踪梯度平方尺度；$$ε$$ 防止分母过小。Adam 仍需要合适的学习率，不保证所有问题上优于其他优化器。

### 4.3 神经网络架构与导数基础

#### 4.3.1 全连接层 vs 卷积层

| 架构 | 连接特点 | 常见用途 |
|---|---|---|
| 全连接层 | 每个输出连接所有输入位置 | 表格特征、网络末端映射等 |
| 卷积层 | 局部连接、共享卷积核参数 | 图像、序列等具有局部结构的数据 |

卷积通过重复使用局部模式减少参数，并利用邻近位置的结构。不能只理解为“删掉一部分连接的 Dense”，参数共享同样关键。

#### 4.3.2 导数的直观定义

导数描述输入发生微小变化时输出的变化率：

$$
\frac{dJ}{dw}=\lim_{\Delta w\to0}
\frac{J(w+\Delta w)-J(w)}{\Delta w}
$$

若 $$J=w²$$，则导数为 $$2w$$；在 $$w=3$$ 附近增加 $$0.001$$，$$J$$ 大约增加 $$0.006$$。偏导数则固定其他变量，只考察某个变量的影响。

#### 4.3.3 反向传播简介

**反向传播（Backpropagation）**在计算图中从损失向前面的参数传递梯度，重复使用链式法则，避免为每个参数独立重算所有中间过程。

若 $$z=wx+b,a=g(z),L=L(a)$$：

$$
\frac{\partial L}{\partial w}
=\frac{\partial L}{\partial a}
\frac{\partial a}{\partial z}x
$$

“反向”指梯度计算方向，不是把预测结果作为原始输入倒着运行网络。

## 五、总结

本篇的主线是：**激活决定表示与输出范围，损失决定训练目标，logits 计算改善数值稳定性，反向传播求梯度，优化器更新参数**。多分类、多标签和回归必须分别选择匹配的输出与损失。

# 【机器学习08】模型评估与选择、偏差与方差、学习曲线

对应原文件：[第08篇 HTML](<吴恩达机器学习完整笔记/【机器学习08】模型评估与选择、偏差与方差、学习曲线 p70-p76.html>)。

## 一、调试学习算法的挑战

模型效果差时，可以收集更多数据、增减特征、改变复杂度或调整正则化。这些措施针对的问题不同，甚至方向相反。

例如，高偏差模型未必能靠增加同分布样本显著改善；高方差模型盲目增加复杂度则可能更糟。因此先诊断“模型连训练集都学不好，还是不能推广到新数据”。

## 二、机器学习诊断法

**诊断法（Diagnostic）**是用于揭示学习算法问题的测试或分析，例如比较训练/验证误差、检查学习曲线、人工分析错误样本。

诊断结果用于缩小实验方向，不是替代实验。数据泄漏、标签错误、分布差异和优化未收敛等问题，也会影响表面上的误差模式。

## 三、评估你的模型

### 3.1 过拟合问题与数据集划分

训练集用于学习参数，独立测试集用于评估未见数据表现。$$70%/30%$$ 是原文示例比例，不是固定规则。

随机划分适合很多独立同分布场景；时间序列要关注时间顺序，同一患者或同一用户的相关记录要防止跨集合泄漏。划分方式应模拟真实使用情形。

### 3.2 线性回归的训练与测试流程

训练时最小化可能包含正则化的目标；评估预测表现时，计算不包含正则项的数据误差：

$$
J_{\mathrm{train}}=\frac1{2m_{\mathrm{train}}}
\sum_{i\in\mathrm{train}}(f(x^{(i)})-y^{(i)})^2
$$

测试集同理，换成测试样本与测试样本数。用同一套已训练参数分别计算，不能为测试集重新拟合参数。

**正则项用于约束训练参数，不是测试样本的预测误差。** 原文讨论过这一写法差异，本笔记统一将二者分开。

### 3.3 分类问题的训练与测试流程

分类可比较交叉熵，也可计算**误分类率**：

$$
E=\frac1m\sum_i\mathbf1(\hat y^{(i)}\ne y^{(i)})
$$

$$1(条件)$$ 是指示函数，条件为真时取1。准确率为 $$1-E$$。概率损失能反映置信度，误分类率直观反映类别是否正确，两者不等价。

类别极不平衡时，单看准确率可能误导，需要第10篇的精确率、召回率等指标。

## 四、模型选择问题

### 4.1 测试集的局限性

**模型选择**包括选择模型类别、特征、网络规模、多项式次数、正则化强度等。如果比较十个模型后按测试误差选最佳者，测试集已经参与选择，其结果往往偏乐观。

即使没有直接用测试集做梯度更新，反复根据其结果调整模型，也属于利用测试信息。

### 4.2 引入交叉验证集

| 集合 | 用途 | 典型操作 |
|---|---|---|
| 训练集 | 学习参数 | 更新 $$w,b$$ |
| 验证集/开发集/CV 集 | 选择超参数与方案 | 选择次数、$$λ$$、架构、阈值 |
| 测试集 | 最终评估 | 对选定方案报告表现 |

原文 $$60%/20%/20%$$ 是示例。此处“交叉验证集”主要指一个**留出的验证集**，不等于已经执行了 K 折交叉验证；K 折是另一种轮换训练与验证的评估程序。

### 4.3 正确的模型选择流程

1. 按训练/验证/测试划分数据。
2. 对每个候选方案，只在训练集学习参数和预处理统计量。
3. 比较验证表现，选择模型和超参数。
4. 冻结选择后，对测试集进行最终评估。

测试结果仍受有限样本、随机性和部署分布差异影响，不能简单承诺“一定无偏、完全代表未来”。若需要在训练加验证集上重训，应事先确定流程，并继续保留独立测试集。

## 五、诊断偏差与方差

### 5.1 理解偏差与方差

**偏差（Bias）**在课程诊断中主要体现为模型没有充分拟合任务规律；**方差（Variance）**主要体现为训练表现与新数据表现差距较大。

严格统计学的偏差/方差涉及对不同训练集的期望；这里主要使用训练与验证误差作为实用诊断线索，二者不是完全相同的数学量。

### 5.2 如何判断是偏差还是方差问题

| 观察结果 | 常见诊断 | 首先考虑 |
|---|---|---|
| 训练误差明显高于合理基准，验证也高 | 高偏差 | 表达能力不足、正则过强、训练不充分 |
| 训练误差低，验证高很多 | 高方差 | 过拟合、样本不足，也需检查分布差异 |
| 训练已较高，验证还高很多 | 两者都可能存在 | 分别检查拟合能力与泛化 |
| 训练和验证均达到目标 | 当前方案较合适 | 再确认测试及实际任务表现 |

“高”“低”必须相对基准或可接受误差而言。例如有噪声的语音任务不能默认训练误差必须接近零。

## 六、正则化与偏差/方差的关系

增加 $$λ$$ 往往增加约束，可能减少过拟合，但过强会增加欠拟合；减小 $$λ$$ 提高拟合自由度，可能降低训练误差，也可能扩大泛化差距。

选择方式：取一组 $$λ$$ → 分别训练 → 比较验证集的数据误差 → 选择较好值 → 最后测试。比较时不要把不同 $$λ$$ 的正则化训练总代价当作统一预测指标。

误差曲线“训练随复杂度降低、验证先降后升”是常见示意趋势，实际有限数据、优化误差和随机训练下不一定严格单调或呈标准 U 形。

## 七、基准性能与学习曲线

### 7.1 建立性能基准

**基准性能（Baseline）**为判断误差提供参照，可来自人类、已有模型、简单规则或业务目标。人类表现是一种参照，不自动等于理论最小误差。

原文语音识别示例：

| 指标 | 数值 | 诊断意义 |
|---|---|---|
| 人类错误率 | $$10.6%$$ | 参考基准 |
| 训练错误率 | $$10.8%$$ | 相比基准高 $$0.2$$ 个百分点 |
| 验证错误率 | $$14.8%$$ | 相比训练高 $$4.0$$ 个百分点 |

这里主要差距在训练与验证之间，应优先研究泛化问题。“可避免偏差”是训练误差与选定基准的差；用人类基准时，只是对改善空间的近似诊断。

### 7.2 学习曲线

此处横轴为**训练样本数量**，纵轴为训练与验证误差。每个样本规模都需要重新训练，再在固定的验证集上评价。

| 情形 | 常见曲线特点 | 对应判断 |
|---|---|---|
| 高偏差 | 两条曲线较接近，最终停在较高误差处 | 单纯增加同类数据通常帮助有限，先提高拟合能力 |
| 高方差 | 训练误差较低，验证误差较高，间距明显 | 增加匹配数据可能缩小差距 |

随着样本增多，训练误差常会上升、验证误差常会下降，但不保证逐点单调。学习曲线用于判断趋势，不应据此绝对断言“加数据永远无用”或“一定有效”。

## 一、策略性调试机器学习模型

上一章回答“问题大致在哪里”，本章回答“接下来优先做什么”。先排除数据划分、标签、代码与优化收敛问题，再结合偏差/方差选择措施。

| 主要问题 | 可尝试的方向 | 为什么可能有效 |
|---|---|---|
| 高偏差 | 增加有信息的特征 | 原始输入可能不足以区分目标 |
| 高偏差 | 添加多项式、改进架构、增大网络 | 提高表示和拟合能力 |
| 高偏差 | 减小过强的正则化、训练更充分 | 减少不必要约束或优化不足 |
| 高方差 | 增加匹配场景的训练数据 | 提供更多可推广规律 |
| 高方差 | 选择特征、限制模型复杂度 | 减少对偶然细节的依赖 |
| 高方差 | 适当增强正则化 | 限制过度拟合 |

这些是候选方向，并不是每次都有效的处方。例如增加无关特征可能同时增加噪声和计算负担。

## 二、偏差与方差的权衡

**偏差-方差权衡**描述模型拟合能力与对训练样本波动的敏感性之间的关系。简单模型容易无法表达规律，复杂模型则有更多机会拟合训练细节。

选择复杂度时，以验证表现为依据。目标不是让两种问题的数值相等，而是在实际资源和数据约束下获得较好的泛化性能。

“增加模型复杂度一定提高方差”只是过于简化的说法。正则化、数据量和训练方法也会改变结果，不能只通过参数个数推断最终效果。

## 三、神经网络中的偏差与方差

调试顺序：

1. **检查训练表现**：若明显差于基准，检查训练是否收敛，尝试更合适的网络、更多单元、较弱正则化等。
2. **检查验证表现**：训练已好而验证明显差，考虑更多数据、正则化、数据增强，并检查分布差异。
3. **重新诊断**：每次改变后记录训练与验证指标，确认改善的是哪种问题。

原文将大网络看作降低偏差的重要工具。但容量大并不保证自动训练成功；优化、输入信息、标签噪声和计算预算仍会构成限制。

L2 可通过 $$Dense(...,kernel_regularizer=tf.keras.regularizers.l2(c))$$ 加入。这里 $$c$$ 的具体尺度应按框架目标定义理解，不能直接假定等于前文 $$λ/(2m)$$ 中的 $$λ$$。

## 四、机器学习开发的迭代循环

**选方案 → 训练 → 诊断 → 调整方案**构成开发循环。方案不仅包含网络架构，也包含数据、特征、损失和评价标准。

每轮实验应记录改动、数据版本、超参数与结果。尽量一次验证一个主要假设，例如“新增医药邮件能否降低该类错误”，避免同时改很多因素后无法解释改善来自哪里。

## 五、错误分析：深入理解模型缺陷

**错误分析（Error analysis）**是人工检查模型失败样本，按错误模式归类，找出值得优先投入的改进方向。

### 5.1 垃圾邮件分类实例

原文以高频词表构造邮件特征。若词表有 10000 个词，每封邮件用一个 10000 维向量表示；某词出现则相应位置为1，否则为0。标签 $$1$$ 表示垃圾邮件。

这是简单的词袋表示：不保留完整词序，但便于说明特征与错误来源。垃圾邮件中的拼写变形、路由、主题等都可能影响分类。

### 5.2 确定优化方向

可以收集更多邮件、分析邮件头、做词干提取，或识别 $$med1cine$$ 之类故意拼错的词。选择应结合**该类错误占比、可解决程度、开发成本**。

某种错误看起来有趣，不代表解决它能显著提高整体指标。错误分析提供的是改进空间估计，不能保证某项技术能够解决该类全部错误。

### 5.3 错误分析流程

原文假设验证集有500封邮件，100封分错。检查这100个错误后发现：

| 错误类型 | 错误样本数 | 占全部错误 |
|---|---|---|
| 医药相关 | 21 | $$21%$$ |
| 故意拼写错误 | 3 | $$3%$$ |
| 异常路由 | 7 | $$7%$$ |
| 网络钓鱼 | 18 | $$18%$$ |

类别可能重叠，例如一封医药邮件也可能有拼写变形，因此不能默认各行可直接相加得到总错误数。

如果拼写错误仅涉及3个失败样本，即使全部修复且不引入新错误，整体错误率也只从 $$100/500=20%$$ 降到 $$97/500=19.4%$$，改善 **0.6 个百分点**，而不是3个百分点。

实际流程：从验证错误中取有代表性的样本 → 设计分类表 → 人工标注与统计 → 排定优先级 → 实施改进 → 用一致的验证方案复评。

## 六、以数据为中心的 AI 视角

### 6.1 策略性地增加数据

根据错误分布补充欠缺场景，例如医药主题、弱光图像或带背景噪声的语音。还要检查标签一致性与覆盖范围，而非只关注样本总数。

定向采集时，应继续用接近真实目标分布的验证集衡量总体效果，避免只改善特定子群、同时损害其他场景。

### 6.2 数据增强技术

**数据增强（Data augmentation）**对已有训练样本施加合理变换，生成有助于泛化的新训练输入，通常保持原任务标签不变。

| 数据类型 | 常见增强 | 条件 |
|---|---|---|
| 图像 | 平移、适当旋转、裁剪、亮度变化 | 不应改变目标类别或删掉关键对象 |
| 语音 | 混入真实背景噪声、模拟通道变化 | 仍保留同一语音内容 |
| 文本 | 任务允许的表述变化 | 必须保持目标语义与标签 |

先划分数据，再只增强训练部分；同一原样本的不同变体若分到训练和测试两边，会形成泄漏。增强也不是任意加噪声，变化应接近真实使用场景。

### 6.3 人工数据合成

**人工数据合成（Artificial data synthesis）**从规则、渲染器或模拟器生成样本及标签。OCR 示例中，可以把不同字体的文字渲染到不同背景，自动得到文字标注。

它与增强的侧重点不同：增强从已有样本做变换，合成可以从头生成。合成数据再多，也应检查与真实数据的差距；背景、字体、噪声过于单一时，模型可能只学到模拟环境特点。

### 6.4 范式转移：从模型为中心到以数据为中心

**以模型为中心**：较固定数据，主要改算法与架构。**以数据为中心**：较固定模型，系统改进标注质量、覆盖、采样和数据处理。

两种思路可以结合。实际问题中，统一模糊标签、清理重复样本、补齐关键场景，可能比继续增加网络层数更有效。

## 七、迁移学习：站在巨人的肩膀上

**迁移学习（Transfer learning）**将源任务或源数据中学到的表示、参数，用于目标任务。常见做法是加载预训练模型，替换输出层，再用目标数据训练。

| 策略 | 更新哪些参数 | 常见考虑 |
|---|---|---|
| 特征提取 | 冻结预训练主干，只训练新输出层 | 目标数据较少、预算有限 |
| 微调（Fine-tuning） | 更新部分或全部预训练参数 | 希望进一步适应目标分布，常用较小学习率 |

流程：选择相关预训练模型 → 保持其要求的输入预处理 → 替换任务输出层 → 先训练新层或直接微调 → 用验证集比较策略。

迁移有效的前提是源表示对目标任务有帮助。同为图像也不意味着一定适合；自然照片与医学图像可能差异很大。少量样本下的效果取决于任务难度和迁移相关性，不能保证几十个样本就足够。

# 【机器学习10】项目生命周期、偏斜类别评估、决策树

## 一、机器学习项目生命周期与部署

### 1.1 机器学习项目的完整生命周期

| 阶段 | 要解决的问题 | 典型产出 |
|---|---|---|
| 定义项目范围 | 为谁解决什么问题，怎样算成功 | 目标、约束、评价标准 |
| 定义和收集数据 | 输入、标签、来源是否可用 | 数据及标注规范 |
| 训练与迭代 | 哪种方案能达到目标 | 模型、诊断结果、实验记录 |
| 部署与维护 | 如何可靠使用并持续评价 | 推理服务、监控与更新流程 |

这些阶段构成循环。上线后遇到的新场景可能推动重新收集数据、修改评价方案和再次训练。

### 1.2 模型部署与 MLOps

**推理（Inference）**是在固定模型参数下对输入计算输出。常见结构是客户端提交输入 → 推理服务执行预处理和模型计算 → 返回预测。

**MLOps**关注模型从实验到生产的工程流程，包括版本管理、部署、日志、监控、扩容和更新。需要同时监测服务延迟、失败率，以及有反馈时的预测质量、输入分布变化。

部署的对象不只是权重文件，还包括特征顺序、类别编码、缩放参数和后处理规则。训练与上线处理不一致，会让模型接收到不同含义的输入。

## 二、偏斜类别下的模型评估

### 2.1 准确率的陷阱

**偏斜类别（Skewed classes）**指各类别样本比例非常不平衡。例如患病率为 $$0.5%$$ 时，全部预测健康就有 $$99.5%$$ 准确率，但完全没有发现患者。

因此，一个 $$99%$$ 准确率的模型不能仅凭该数值证明有用。必须问模型发现了多少正类，产生了多少误报，以及不同错误的代价。

### 2.2 精确率与召回率

先明确正类，例如“患病”为1：

| 真实情况 | 预测为正 | 预测为负 |
|---|---|---|
| 真实为正 | TP：正确发现，15 | FN：漏报，10 |
| 真实为负 | FP：误报，5 | TN：正确排除，70 |

**精确率（Precision）**：预测为正的样本中，有多少真的为正。

$$
P=\frac{TP}{TP+FP}=\frac{15}{20}=0.75
$$

**召回率（Recall）**：真实正样本中，有多少被找出来。

$$
R=\frac{TP}{TP+FN}=\frac{15}{25}=0.60
$$

同一例子的准确率为 $$(15+70)/100=85%$$。记忆：**精确率看“报出来的准不准”，召回率看“该找的找全没有”**。分母为零时指标需要按评估工具的约定处理。

### 2.3 指标的权衡

对于固定概率预测，阈值升高，预测为正的集合缩小；阈值降低，集合扩大。因此降低阈值时召回率不会下降，但误报通常增加。

精确率往往与召回率发生权衡，但在有限数据上不保证随阈值严格单调。可在验证集查看 PR 曲线，再按业务约束选阈值，例如“召回至少达到某值时尽量减少误报”。

### 2.4 F1 分数：综合评估指标

**F1**是精确率与召回率的调和平均：

$$
F_1=\frac{2PR}{P+R}
=\frac{2TP}{2TP+FP+FN}
$$

上述例子 $$F1=30/(30+5+10)=2/3≈0.6667$$。任一指标很低，F1 都难以很高，因此比简单算术平均更强调二者共同表现。

F1 不直接使用 TN，也不表达所有业务代价。若漏报与误报的重要性不同，可能需要其他指标或明确的成本函数，而不是默认 F1 最合适。

## 三、决策树模型详解

### 3.1 模型结构与预测

**决策树（Decision tree）**通过一系列条件判断，把输入路由到某个叶节点，输出类别或数值。

| 结构 | 含义 |
|---|---|
| 根节点 | 起点，包含第一个判断 |
| 决策/内部节点 | 按某个特征条件分裂 |
| 分支 | 条件判断的不同结果 |
| 叶节点 | 不再分裂，保存预测结果 |

猫分类示例中，可依次判断耳形、脸形、胡须。预测新样本时沿唯一满足条件的路径向下，不需要把整棵树所有分支都走一遍。

### 3.2 决策树学习的核心问题

学习树结构主要回答：

1. **在哪个特征、哪个条件上分裂？** 希望分裂后各子节点更“纯”，即类别更集中。
2. **什么时候停止？** 不能无限细分到把训练噪声都记下来。

停止条件包括节点已纯、达到最大深度、样本太少、分裂收益不足等。复杂度控制影响泛化能力。

### 3.3 用熵衡量不纯度

**熵（Entropy）**在这里衡量节点内类别混杂程度。设正类占比为 $$p$$：

$$
H(p)=-p\log_2p-(1-p)\log_2(1-p)
$$

约定 $$0log 0=0$$。$$p=0$$ 或 $$1$$ 时所有样本同类，熵为0；$$p=0.5$$ 时二分类最混杂，熵为1。

节点里样本多不等于熵高，熵取决于类别比例。另一个常见分类不纯度指标是 Gini，本篇原文重点使用熵。

### 3.4 信息增益：选择最佳分裂

**信息增益（Information gain）**是分裂前熵减去分裂后各子节点的加权熵：

$$
IG=H(p_{\mathrm{root}})
-\left[\frac{m_L}{m}H(p_L)+\frac{m_R}{m}H(p_R)\right]
$$

权重由子节点样本数量决定，不能无论节点大小都简单取平均。原文根节点有一半正类，熵为1：

| 候选特征 | 信息增益 |
|---|---|
| 耳形 | $$1-0.5H(0.8)-0.5H(0.2)≈0.2781$$ |
| 脸形 | 约 $$0.03$$ |
| 胡须 | 约 $$0.12$$ |

所以该节点选择耳形。信息增益评价的是当前这次分裂，不保证贪心选择得到全局最优整棵树。

### 3.5 决策树学习算法流程

从包含全部训练样本的根节点开始 → 枚举可用分裂 → 计算收益 → 选收益最大的有效分裂 → 对各子节点递归重复 → 满足停止条件后形成叶节点。

分类叶节点可以输出多数类，也可以依据节点内类别比例给出概率估计。深树常有较低训练误差，但需要验证集帮助控制过拟合。

# 【机器学习11】决策树进阶、随机森林、XGBoost、模型对比

对应原文件：[第11篇 HTML](<吴恩达机器学习完整笔记/【机器学习11】决策树进阶、随机森林、XGBoost、模型对比 p92-p99.html>)。

## 一、决策树的特征处理

### 1.1 处理多值分类特征：独热编码

**独热编码（One-hot encoding）**为每个可能类别创建一个二元特征，当前类别所在位置为1，其他位置为0。

| 耳形 | 尖耳 | 椭圆耳 | 软塌耳 |
|---|---|---|---|
| 尖耳 | 1 | 0 | 0 |
| 椭圆耳 | 0 | 1 | 0 |
| 软塌耳 | 0 | 0 | 1 |

它避免把类别编码为 $$1,2,3$$ 后无意引入大小与间距关系。训练时应固定类别表，并决定如何处理未知类别。

原文使用这种通用方法说明特征数值化；某些树实现也支持原生类别处理，不能认为所有决策树都必须先 one-hot。

### 1.2 处理连续特征

连续变量通过阈值产生二元判断，例如 $$体重≤9$$。把当前节点样本的该特征排序，常可在相邻不同取值的中点设置候选阈值。

对每个候选计算信息增益，比较所有特征与阈值，选收益最大的有效分裂。同一连续特征可以在后续不同节点再次使用不同阈值。

## 二、用于回归任务的决策树

### 2.1 回归树的结构与预测

**回归树（Regression tree）**的叶节点输出数值。在平方误差目标下，叶节点预测值为落入该叶节点的训练目标平均值：

$$
\hat y_{\mathrm{leaf}}=\frac1{|S|}\sum_{i\in S}y^{(i)}
$$

原文例子 $$(7.2+8.4+7.6+10.2)/4=8.35$$。新样本到达这个叶节点时，不论其精确特征是多少，当前这棵树都预测为 $$8.35$$，因此单棵回归树形成分段常数函数。

### 2.2 回归树的分裂标准：方差缩减

分类关心类别混杂，回归关心同一节点内数值目标是否接近。以节点目标方差衡量：

$$
\operatorname{Var}(S)=\frac1{|S|}
\sum_{i\in S}(y^{(i)}-\bar y_S)^2
$$

分裂收益为：

$$
\Delta=\operatorname{Var}(S)
-\frac{|S_L|}{|S|}\operatorname{Var}(S_L)
-\frac{|S_R|}{|S|}\operatorname{Var}(S_R)
$$

原文按耳形分裂：$$20.51-(0.5×1.47+0.5×21.87)=8.84$$。比较候选的方差缩减，选最大的分裂，再递归继续。

## 三、集成学习：从决策树到森林

### 3.1 决策树的敏感性

训练数据稍有变化，最优根分裂可能改变，后续整棵树也随之变化。这种对数据扰动敏感的现象体现出高方差。

限制树深可以降低复杂度；另一个方向是训练多个有差异的模型，综合它们的输出。

### 3.2 树集成：群体的智慧

**集成学习（Ensemble learning）**组合多个模型预测，期望获得更稳健的结果。分类可投票或平均概率，回归通常平均数值。

如果模型错误并不完全一致，组合有助于抵消部分波动；若所有树完全相同，则集成没有带来相应多样性。集成通常有益，但不能保证超过每一个单模型。

### 3.3 Bagging 与随机森林

**Bootstrap（自助采样）**从原数据有放回抽样。抽出的新训练集可以仍有 $$m$$ 行，但包含重复样本，也有原样本未被抽到。

**Bagging（Bootstrap aggregating）**：反复生成自助训练集，分别训练多棵树，最后合并预测。各棵树的训练可以相对独立开展。

**随机森林（Random forest）**在常见 Bagging 树的基础上，增加节点分裂时的随机特征选择：每个节点先随机抽一部分特征，只在这些特征里寻找最佳分裂。

| 方法 | 样本随机性 | 分裂特征随机性 |
|---|---|---|
| Bagging 树 | 常用有放回采样 | 通常可考虑全部特征 |
| 随机森林 | 常用有放回采样 | 每节点只考察随机特征子集 |

这样可以降低树间相关性。分类中 $$k≈√n$$ 是常见启发式之一，不是所有任务和实现都固定如此，也不是为整棵树只抽一次特征后永远不变。

### 3.4 提升法与 XGBoost

**提升法（Boosting）**按顺序添加新模型，让新模型针对当前集成尚未处理好的部分继续改进。

不同提升算法实现方式不同：

- **AdaBoost**通过调整样本权重，增加部分困难样本的影响。
- **梯度提升（Gradient boosting）**让新模型拟合损失的负梯度；平方误差下可理解为拟合残差。
- **XGBoost**是梯度提升树的一种实现，包含正则化、分裂优化等设计。

因此不能把所有 Boosting 都解释为“把分错样本的采样权重调大”，也不能把分类任务中的提升一律等同于拟合普通数值残差。

梯度提升的基本形式：

$$
F_t(x)=F_{t-1}(x)+\eta h_t(x)
$$

$$h_t$$ 是本轮新增树，$$η$$ 是收缩步长。常需调节树数量、树深、学习率、采样比例和正则化。原文的接口区分是：分类用 $$XGBClassifier$$，回归用 $$XGBRegressor$$，通过 $$fit/predict$$ 训练与预测。

## 四、决策树与神经网络的对比

| 方面 | 决策树与树集成 | 神经网络 |
|---|---|---|
| 表格数据 | 常是值得优先比较的强基线 | 也能使用，需适当表示和训练 |
| 原始图像、音频、文本 | 通常不是直接建模的首选 | 可利用卷积、序列等专门架构 |
| 可解释性 | 小树路径直观，大型集成更复杂 | 通常需要额外解释方法 |
| 特征缩放 | 常规阈值分裂通常不敏感 | 常需关注尺度和归一化 |
| 迁移学习 | 常见方式与深度模型不同 | 可借助预训练表示 |
| 计算开销 | 依树数量、深度与实现而定 | 依网络规模、硬件与批量而定 |

原文给的是选型经验，不能推导出“神经网络对所有数据都更好”或“树一定更快”。最终按数据性质、验证结果、解释需求和部署预算选择。

# 【机器学习12】无监督学习：K-均值聚类与异常检测

对应原文件：[第12篇 HTML](<吴恩达机器学习完整笔记/【机器学习12】无监督学习：K-均值聚类与异常检测 p102-p111.html>)。

## 一、监督学习之外的机器学习

本阶段从依赖输入与标签的监督学习，转向发现无标签数据结构的方法。先学习聚类与分布式异常检测，后续进入推荐系统与强化学习。

知识分类要区分：监督/无监督/强化学习是学习设定；推荐系统是应用；K-均值、PCA 是具体方法。

## 二、无监督学习：发现数据的内在结构

### 2.1 监督学习与无监督学习的对比

监督分类已经知道训练样本的正确类别；聚类只有特征，不预先给出每个样本属于哪组。算法根据距离、相似性或分布假设划分。

分组结果会受特征缩放、簇数量与相似性定义影响，因此“发现结构”不是脱离建模选择自动得到唯一答案。

### 2.2 聚类的应用

用户分群用于了解消费行为，新闻聚类用于组织主题，计算资源聚类用于发现相近负载模式，服装尺码设计用于把体型划成若干实用组。

应用目的会影响特征与 $$K$$ 的选择：面向销售的用户群可能与面向技术支持的用户群完全不同。

## 三、K-均值聚类算法

### 3.1 K-均值算法的核心步骤

**K-均值（K-means）**用 $$K$$ 个**簇中心/质心（centroid）**代表数据组，反复执行“分配样本”和“更新中心”。

$$K$$ 是预先选择的簇数；$$c^{(i)}$$ 是第 $$i$$ 个样本的簇编号；$$μ_k$$ 是第 $$k$$ 个簇的中心向量。编号本身没有顺序意义。

### 3.2 K-均值算法的迭代过程演示

对于数据 $$[1,2,8,9]$$，令 $$K=2$$，初始中心为 $$1,8$$：

1. 按最近中心分配，得到 $${1,2}$$ 与 $${8,9}$$。
2. 更新中心为 $$1.5,8.5$$。
3. 再分配时两组不变，中心也不再变化。

高维情况下完全相同，只是计算的是向量间距离，中心是各特征坐标的平均值。

### 3.3 K-均值算法伪代码

$$
c^{(i)}\leftarrow\arg\min_{k\in\{1,\ldots,K\}}
\|\mathbf x^{(i)}-\boldsymbol\mu_k\|^2
$$

$$
\boldsymbol\mu_k\leftarrow\frac1{|C_k|}
\sum_{i:c^{(i)}=k}\mathbf x^{(i)}
$$

流程：初始化中心 → 分配所有样本 → 更新所有中心 → 重复到稳定或达到迭代上限。若出现空簇，均值无法计算，应重新初始化该中心等，不能直接除以零。

### 3.4 K-均值的应用场景

当以欧氏距离衡量的相近性有意义、希望用中心概括分组时可以考虑 K-均值。它倾向于形成围绕中心的紧凑簇。

对弯月状、密度差异大或包含强异常值的数据，结果可能不理想。相距近是否代表相似，还取决于特征缩放，因此通常需要预处理。

## 四、K-均值算法的优化目标

### 4.1 代价函数：失真

**失真（Distortion）**是样本到其所属中心的平均平方距离：

$$
J(c,\mu)=\frac1m\sum_{i=1}^m
\|\mathbf x^{(i)}-\boldsymbol\mu_{c^{(i)}}\|^2
$$

误差越小，表示样本围绕对应中心越集中。这是聚类的内部目标，不自动等于业务价值。

前面的数值例中，四个点到中心的平方距离均为 $$0.25$$，所以 $$J=0.25$$。

### 4.2 K-均值算法如何最小化代价函数

固定中心时，分给最近中心使每个样本的距离尽可能小；固定分组时，用均值作为中心使组内平方距离和最小。

两步交替通常使代价不增加，但目标不是整体凸优化，可能停在局部较优解；因此初始化很重要。

## 五、K-均值算法的实践要点

### 5.1 随机初始化与局部最优

原文建议从训练样本中随机选 $$K$$ 个点作为初始中心，重复运行多次，保留最终代价较小的结果。原文的几十到上千次是试验范围示例，实际应结合数据规模和初始化策略。

不同运行簇编号可能互换，但分组完全相同，比较结果时不要把“簇编号不同”直接当作结构不同。

### 5.2 如何选择聚类数量 $$K$$

**肘部法（Elbow method）**画出 $$K$$ 与最小代价的关系，寻找下降速度明显放缓的位置。并非所有数据都有清晰肘点。

理论上，允许更多中心不会使最优失真变差，因此不能简单选择 $$J$$ 最小的 $$K$$，否则很容易选择过多簇。实际局部优化与随机初始化会让观测曲线出现波动。

另一种方式是用下游目标选择，例如衣服尺码数量要综合库存、用户覆盖和制造成本，而不只看距离。

## 六、异常检测

### 6.1 异常检测的基本思想

使用大量正常样本学习“正常数据通常出现在哪里”，对新样本计算密度评分，若评分过低则标记异常：

$$
p(\mathbf x)<\epsilon
$$

$$ε$$ 是异常阈值，与强化学习中的探索概率虽然常用同一字母，却不是同一参数。

这里的 $$p(x)$$ 是**概率密度**，不是“这个点为异常的概率”；连续分布在单点的概率为零，密度值甚至可以大于1。

### 6.2 异常检测的应用

服务器监控中，CPU、内存、延迟的异常组合可能表示故障；制造设备中，温度与振动偏离正常模式可能提示问题。

异常不一定在每个特征上都极端。某两个指标单独都正常，它们的组合却可能不常见；简单独立分布模型未必能自动捕捉这种关系，下一篇介绍特征工程。

### 6.3 基于高斯分布的异常检测算法

**高斯分布（Gaussian/Normal distribution）**由均值 $$μ$$ 和方差 $$σ²$$ 决定：

$$
p(x;\mu,\sigma^2)=\frac1{\sqrt{2\pi\sigma^2}}
\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

原文对每个特征分别拟合：

$$
\mu_j=\frac1m\sum_i x_j^{(i)},\qquad
\sigma_j^2=\frac1m\sum_i(x_j^{(i)}-\mu_j)^2
$$

此处是高斯参数的极大似然估计，方差分母为 $$m$$。假定特征独立或用独立近似，联合密度为：

$$
p(\mathbf x)=\prod_{j=1}^{n}p(x_j;\mu_j,\sigma_j^2)
$$

步骤：选择特征 → 估计各特征参数 → 对新输入计算联合密度 → 与阈值比较。高维中宜使用对数密度求和，防止很多小数相乘下溢；零方差特征需特殊处理。

### 6.4 异常检测算法的评估

训练集主要使用正常样本；验证集和测试集保留带标签的正常与异常样本，用来选择阈值、计算精确率/召回率/F1并最终评估。

这说明“训练时未用异常标签建模”与“验证时使用标签衡量效果”不矛盾。

增大 $$ε$$ 会把更多样本标为异常，通常提高召回并增加误报；通过验证集选择合适阈值，再在独立测试集评估，不能直接靠训练密度大小判断效果好坏。

# 【机器学习13】异常检测优化、推荐系统、协同过滤

对应原文件：[第13篇 HTML](<吴恩达机器学习完整笔记/【机器学习13】异常检测优化、推荐系统、协同过滤 p112-119.html>)。

## 一、异常检测的高级主题

### 1.1 异常检测与监督学习的对比

两者都可能处理“正常/异常”，但训练条件不同：

| 情况 | 基于正常分布的异常检测 | 监督二分类 |
|---|---|---|
| 数据条件 | 正常样本多，异常样本极少 | 有较充足的正负标签 |
| 对异常的认识 | 类型多，未来可能出现新型异常 | 希望学习已知异常的共同特征 |
| 训练重点 | 学习正常模式，发现偏离 | 学习区分两类的边界 |
| 示例 | 新型设备故障、未见过的缺陷 | 已知划痕检测、垃圾邮件识别 |

原文“0～20个异常样本”用于说明异常稀少，不是选算法的硬性分界。实际还要考虑异常能否在所选特征上表现为低密度，以及误报是否可接受。

### 1.2 异常检测的错误分析与特征工程

如果异常样本也获得较高正常密度，可能是输入特征无法揭示异常，或者模型分布假设不合适。先检查漏报和误报，再决定增加什么信息。

数据中心例子：CPU负载高、网络流量低，两者单独未必异常，但“高CPU且低流量”的组合值得关注，可以构造：

$$
x_{\mathrm{ratio}}=\frac{\mathrm{CPU\ load}}
{\mathrm{network\ traffic}+\delta}
$$

$$δ$$ 是避免分母为零的小量，需与特征单位配合。构造比例时还应避免正常的低流量样本被无意义放大。

若单变量分布明显偏斜，可以考虑适当变换，如正数据的对数；有零值时检查是否适合 $$log1p$$，含负值时不能直接套 $$log(x)$$。变换后要重新拟合分布与验证阈值，不要求所有真实特征都严格高斯。

## 二、推荐系统入门

### 2.1 问题定义：电影评分预测

**推荐系统（Recommender system）**根据用户、物品及上下文信息，预测偏好并选择值得展示的物品。评分预测是其中一种任务。

设评分矩阵的**行是电影、列是用户**：

| 符号 | 含义 |
|---|---|
| $$n_m$$ | 电影数量 |
| $$n_u$$ | 用户数量 |
| $$y(i,j)$$ | 用户 $$j$$ 对电影 $$i$$ 的已知评分 |
| $$r(i,j)$$ | 该评分是否可用，可用为1，否则为0 |
| $$x^{(i)}$$ | 电影 $$i$$ 的特征向量 |
| $$w^{(j)},b^{(j)}$$ | 用户 $$j$$ 的偏好参数与偏置 |

目标是预测未评分的位置。**没有评分不是评分为0**：缺失通常表示未观看、未展示或未反馈，不能直接当成差评。

### 2.2 基于内容的推荐算法

**基于内容的推荐（Content-based recommendation）**利用物品或用户的属性匹配偏好。原文首先假设已有电影特征，例如浪漫程度、动作程度，为每个用户分别学习线性模型：

$$
\hat y(i,j)=(\mathbf w^{(j)})^\top\mathbf x^{(i)}+b^{(j)}
$$

假设电影特征 $$[0.9,0.1]$$，某用户权重 $$[5,0]$$、偏置 $$0.45$$，则预测为 $$4.95$$。这个例子说明“物品特征怎样与用户偏好匹配”，不表示真实潜在维度一定可解释成浪漫或动作。

### 2.3 基于内容的代价函数

对单个用户，可以使用只包含其已评分电影的均方误差加 L2。若其评分数量为 $$m_j$$：

$$
J_j=\frac1{2m_j}\sum_{i:r(i,j)=1}
\left((w^{(j)})^\top x^{(i)}+b^{(j)}-y(i,j)\right)^2
+\frac{\lambda}{2m_j}\|w^{(j)}\|^2
$$

后续协同过滤统一采用**未按用户分别平均**的总和形式：

$$
J=\frac12\sum_{i,j:r(i,j)=1}(\hat y(i,j)-y(i,j))^2
+\frac\lambda2\sum_j\|w^{(j)}\|^2
$$

两种写法在每个用户模型独立、电影特征固定时可给出相同的单用户最优解，但总代价及梯度尺度不同；一旦共享学习物品参数，不同用户权重也会影响结果。不能把不同 $$m_j$$ 直接当成共同常数省略。

## 三、协同过滤

### 3.1 问题的另一视角：学习电影特征

如果用户偏好 $$w,b$$ 已知，可以从他们对电影的评分反推电影特征 $$x$$。喜欢相近内容的用户给某电影相似高分，就为该电影的表示提供约束。

这与前面“固定电影特征、学习用户偏好”是同一个预测式的不同优化视角。

### 3.2 协同过滤算法：同时学习

**协同过滤（Collaborative filtering）**利用多用户与多物品的交互模式学习偏好。课程中的方法同时学习用户向量、电影向量和用户偏置：

$$
J(X,W,b)=\frac12\sum_{i,j:r(i,j)=1}
\left((w^{(j)})^\top x^{(i)}+b^{(j)}-y(i,j)\right)^2
+\frac\lambda2\sum_j\|w^{(j)}\|^2
+\frac\lambda2\sum_i\|x^{(i)}\|^2
$$

第一项拟合已知评分，后两项约束用户与电影向量。通常不正则化偏置 $$b$$。

令已观测项误差为 $$e_{ij}$$，梯度为：

$$
\frac{\partial J}{\partial w^{(j)}}=
\sum_{i:r(i,j)=1}e_{ij}x^{(i)}+\lambda w^{(j)}
$$

$$
\frac{\partial J}{\partial x^{(i)}}=
\sum_{j:r(i,j)=1}e_{ij}w^{(j)}+\lambda x^{(i)},\qquad
\frac{\partial J}{\partial b^{(j)}}=
\sum_{i:r(i,j)=1}e_{ij}
$$

可以同时做梯度更新；也存在交替固定一组参数、优化另一组的方法。由于含用户向量与物品向量的乘积，联合目标通常非凸。

这些特征由数据学出，称为**潜在因子/嵌入（latent factors/embeddings）**。对向量空间作某些共同变换仍可保留相同预测，因此不能给每一维强加固定、唯一的语义。

## 四、协同过滤的扩展与实践

### 4.1 二元标签推荐

没有星级评分时，可以建模点击、购买、观看等交互：

- $$1$$：发生目标行为。
- $$0$$：在定义的曝光条件下没有发生目标行为。
- 缺失：没有相应观测，不能自动理解为负反馈。

使用 $$p_{ij}=g((w^{(j)})^\top x^{(i)}+b^{(j)})$$ 预测交互概率，并把平方误差换成已知标签上的二元交叉熵，保留合适的正则化。

实际曝光机制与负样本选择会影响学习目标。用户未点击可能因为没看到，并非一定不喜欢。

### 4.2 冷启动问题与均值归一化

**冷启动（Cold start）**指新用户或新物品缺少历史交互，无法充分学习其专属表示。

对每部电影计算已有评分均值：

$$
\mu_i=\frac{\sum_{j:r(i,j)=1}y(i,j)}
{\sum_jr(i,j)}
$$

只对已知评分做中心化 $$y_{\mathrm{norm}}(i,j)=y(i,j)-μ_i$$，训练后恢复：

$$
\hat y(i,j)=(w^{(j)})^\top x^{(i)}+b^{(j)}+\mu_i
$$

若新用户没有历史，L2 会推动其被惩罚的向量 $$w$$ 接近零；但**未加正则的偏置 $$b$$ 不会被该正则项强制归零**。可以把新用户偏置初始化为零，作为默认策略，此时预测回退到各电影平均分。

这是对原文冷启动解释的修正。均值回退提供合理起点，并未解决完整的个性化；新电影连均值也没有时，还需要全局基线、内容特征或主动收集反馈。

## 五、算法实现：TensorFlow 中的梯度下降

### 5.1 梯度下降回顾

现在需要优化的不仅是用户权重，还有物品特征和偏置。统一记参数为 $$θ$$，每轮根据 $$θ←θ-α∇J$$ 更新，所有梯度应来自同一次前向计算。

在矩阵约定中，$$X$$ 为 $$(n_m,d)$$，$$W$$ 为 $$(n_u,d)$$，$$b$$ 为 $$(1,n_u)$$，预测矩阵为 $$X @ W.T + b$$，形状与评分矩阵一致。

### 5.2 TensorFlow 中的自定义训练循环

**自动微分（Automatic differentiation）**根据实际执行的可微运算计算导数。$$tf.Variable$$ 保存可训练参数，$$tf.GradientTape$$ 记录块内运算，$$tape.gradient$$ 求损失对参数的梯度。

损失所依赖的前向计算应放在 Tape 范围内；若先在外面计算一个不再与参数连接的结果，可能无法获得所需梯度。

### 5.3 协同过滤的 TensorFlow 实现

以下函数假设 $$Y$$ 是已填充缺失位置的有限数值矩阵、$$R$$ 是同形状的 $$0/1$$ 掩码。中心化与均值还原可在调用前后完成。

```python
import tensorflow as tf

def train_collaborative_filter(Y, R, dimensions=10,
                               reg=0.1, steps=200):
    Y = tf.convert_to_tensor(Y, dtype=tf.float32)
    R = tf.convert_to_tensor(R, dtype=tf.float32)
    n_movies, n_users = Y.shape
    X = tf.Variable(tf.random.normal([n_movies, dimensions],
                                     stddev=0.1))
    W = tf.Variable(tf.random.normal([n_users, dimensions],
                                     stddev=0.1))
    b = tf.Variable(tf.zeros([1, n_users]))
    optimizer = tf.keras.optimizers.Adam(learning_rate=0.01)
    parameters = [X, W, b]
    for _ in range(steps):
        with tf.GradientTape() as tape:
            prediction = tf.matmul(X, W, transpose_b=True) + b
            error = (prediction - Y) * R
            data_cost = 0.5 * tf.reduce_sum(tf.square(error))
            penalty = 0.5 * reg * (
                tf.reduce_sum(tf.square(X))
                + tf.reduce_sum(tf.square(W))
            )
            cost = data_cost + penalty
        gradients = tape.gradient(cost, parameters)
        optimizer.apply_gradients(zip(gradients, parameters))
    return X, W, b
```

缺失位置可以用0占位，但必须由 $$R$$ 排除，因此不会被训练成真实0分。不能用 $$NaN$$ 占位后认为乘0就会消失，$$NaN×0$$ 仍是 $$NaN$$。

# 【机器学习14】深度学习推荐系统、降维技术 PCA

对应原文件：[第14篇 HTML](<吴恩达机器学习完整笔记/【机器学习14】深度学习推荐系统、降维技术PCA p120-128.html>)。

## 一、推荐系统的高级应用与方法

### 1.1 利用特征向量寻找相似物品

协同过滤学到的物品向量可用于计算相似性：

$$
d(i,k)=\|x^{(i)}-x^{(k)}\|^2
$$

在这一表示与度量下，距离较小表示更相近。检索时排除物品自身，取若干最近邻。

“相似”由训练目标与特征空间定义，不一定等同于电影题材相同。例如两个不同题材作品可能吸引相同用户，因而在行为嵌入中靠近。

### 1.2 协同过滤的局限性与混合方法

传统矩阵分解依赖交互历史，新用户和新物品缺少约束。**混合推荐**结合交互数据与额外信息，例如电影类型、年份、文本以及用户明确表达的偏好。

内容特征可为新物品提供表示，但其缺失、错误或与偏好不相关时，仍不能保证良好推荐。

### 1.3 协同过滤与基于内容的过滤对比

| 维度 | 协同过滤 | 基于内容的推荐 |
|---|---|---|
| 核心依据 | 用户与物品的交互模式 | 用户偏好与物品属性匹配 |
| 常用信息 | 评分、点击、购买等 | 类型、描述、属性及用户特征 |
| 典型思路 | 共同评分模式反映潜在偏好 | 喜欢某些属性，就推荐相近属性物品 |
| 冷启动 | 历史不足时困难 | 有可用内容时可以提供帮助 |

原文“与你相似的用户也喜欢”是协同思想的直观解释；矩阵分解不一定显式查找一组最近邻用户。

### 1.4 基于深度学习的推荐系统

**双塔模型（Two-tower model）**分别用用户网络与物品网络，把两边原始特征转换为同维度嵌入：

$$
v_u=f_{\theta_u}(x_u),\qquad
v_m=g_{\theta_m}(x_m),\qquad
s(u,m)=v_u^\top v_m
$$

原始用户特征可以有100维，物品特征80维；两塔输出都为32维，就可以计算点积。两塔的输入维数和内部结构不必相同，**输出维数要匹配**。

| 组成 | 作用 |
|---|---|
| 用户塔 | 综合用户属性、历史偏好等生成用户表示 |
| 物品塔 | 综合物品属性、内容等生成物品表示 |
| 点积/匹配层 | 计算两种表示的匹配分数 |
| 训练损失 | 按评分或交互任务优化表示 |

评分预测可用点积加适当偏置，配回归损失；二元交互预测可把分数当 logit，配二元交叉熵。点积本身不是概率。

物品嵌入可离线预计算，并建立近邻索引。不需要为百万物品保存完整的两两相似度矩阵，后者存储量按物品数平方增长。

### 1.5 大规模推荐系统：召回与排序

**召回（Retrieval）**从海量物品中快速找出较小的候选集，重视覆盖潜在相关物品。可以合并相似物品、用户偏好类型、热门榜等多路候选，再去重并过滤不适合展示的物品。

**排序（Ranking）**对候选进行更精细的打分，按目标组织最终展示顺序。排序可以使用更丰富的交叉特征或复杂模型，不限定只能使用双塔。

这里“召回阶段”是系统环节；“召回率”是评价指标，二者有联系但不能混为一词的同一定义。

| 环节 | 数据规模 | 主要关注 |
|---|---|---|
| 召回 | 从百万级中找几百或几千个 | 速度、候选覆盖 |
| 排序 | 对有限候选精细处理 | 相关性、目标效用、时延 |

候选数量增加通常提高计算成本，但质量不保证一直提高。原文关于召回“快且全”的表述应理解为尽量减少相关物品漏选，而不是排除更多可能相关项。

### 1.6 TensorFlow 实现概览

```python
import tensorflow as tf

def make_tower(input_dimension):
    return tf.keras.Sequential([
        tf.keras.Input(shape=(input_dimension,)),
        tf.keras.layers.Dense(256, activation="relu"),
        tf.keras.layers.Dense(128, activation="relu"),
        tf.keras.layers.Dense(32),
    ])

def build_rating_model():
    user_tower = make_tower(100)
    item_tower = make_tower(80)
    user_input = tf.keras.Input(shape=(100,))
    item_input = tf.keras.Input(shape=(80,))
    vu = user_tower(user_input)
    vm = item_tower(item_input)
    score = tf.keras.layers.Dot(axes=1)([vu, vm])
    model = tf.keras.Model(
        inputs=[user_input, item_input], outputs=score
    )
    model.compile(
        optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
        loss=tf.keras.losses.MeanSquaredError(),
    )
    return model, user_tower, item_tower
```

原文把两侧嵌入做 L2 归一化作为可选步骤。需注意：**单位向量的点积只能在 $$[-1,1]$$ 内**；若直接预测1～5分，这个输出范围不匹配，需另加缩放/偏置或变换目标。此处评分示例不归一化嵌入。

嵌入归一化与 L2 参数正则化也不同：前者改变表示长度，后者向训练目标加入权重惩罚。

## 二、降维与主成分分析（PCA）

### 2.1 降维的动机

**降维**把原来 $$n$$ 个特征表示为 $$k<n$$ 个新特征。原始变量可能高度相关，例如车长与车宽都反映车辆整体尺寸，直接丢弃一个变量可能损失有用变化。

PCA 使用原特征的线性组合构造新坐标，保留数据主要变化方向。其“信息”主要指方差意义下的信息，不自动等同于对下游预测最有用的信息。

### 2.2 PCA 的应用：数据可视化

将50维数据投影到2维或3维后，可以绘制散点图，观察群组、异常和整体分布。

低维图会丢失信息，图上重叠的样本未必在原空间相近；没有明显分组也不等于原数据没有可分类结构。

### 2.3 主成分分析算法

**PCA（Principal Component Analysis，主成分分析）**寻找相互正交的线性方向，使保留方向上的投影方差尽可能大；等价地，在相应条件下最小化低维重建的平方误差。

步骤：

1. 用训练集均值中心化数据。
2. 如果单位或尺度不应主导结果，按任务需要先标准化。
3. 通过协方差矩阵特征分解或数据矩阵 SVD，得到按方差大小排列的方向。
4. 保留前 $$k$$ 个方向，将样本投影得到低维坐标。

**主成分方向**是单位向量；**主成分得分**是样本投影后的坐标，二者不要混淆。第一方向投影方差最大，第二方向在与第一方向正交的约束下方差最大，依此类推。

以“样本按行、方向按列”表示：

$$
X_c=X-\mu,\qquad Z=X_cU_k
$$

$$X_c$$ 为 $$(m,n)$$，$$U_k$$ 为 $$(n,k)$$，$$Z$$ 为 $$(m,k)$$。方向向量正负号翻转表示同一条轴，不影响保留的子空间与重建。

### 2.4 PCA 与线性回归的区别

| 对比 | 线性回归 | PCA |
|---|---|---|
| 学习设定 | 监督，有目标 $$y$$ | 无监督，只使用输入特征 |
| 目标 | 减少目标预测误差 | 保留投影方差/减少重建误差 |
| 几何距离 | 简单二维例中沿目标轴的残差 | 到子空间的正交投影距离 |
| 输出含义 | 预测目标 | 新坐标表示 |

PCA 不会因为一个低方差方向对标签很有用而自动保留它，因为它根本没有使用标签。

### 2.5 数据重建与实践

从低维坐标近似重建：

$$
\hat X=ZU_k^\top+\mu
$$

若之前还做了标准化，需要再反变换到原单位。保留全部有效方向时可以在浮点误差内恢复输入；真正降维时通常只有近似重建。

**解释方差比例**表示某个主成分方差占总方差的比例，可通过累计比例辅助选择 $$k$$，例如保留95%的总方差，但最终应看用途。

```python
import numpy as np
from sklearn.decomposition import PCA

X = np.array([
    [1, 1], [2, 1], [3, 2],
    [-1, -1], [-2, -1], [-3, -2],
], dtype=float)

pca_1 = PCA(n_components=1)
Z1 = pca_1.fit_transform(X)
X_reconstructed = pca_1.inverse_transform(Z1)
ratio_1 = pca_1.explained_variance_ratio_

pca_2 = PCA(n_components=2)
Z2 = pca_2.fit_transform(X)
X_restored = pca_2.inverse_transform(Z2)
```

对原文这组数据，第一主成分解释方差比例约 $$0.99244289$$，即 $$99.24%$$，第二个约 $$0.7557%$$。保留1维时 $$Z1.shape=(6,1)$$，重建为 $$(6,2)$$；保留2维只改变坐标系，没有实际降维。

$$sklearn.PCA$$ 会中心化，但**不会自动把每个原始特征标准化为单位方差**。需要标准化时先在训练集拟合相应处理；测试样本只能调用已拟合变换，不能重新 $$fit$$。

### 2.6 PCA 的应用总结

主要用途是可视化、压缩、去除部分线性冗余，也可能减少后续计算。是否提升监督任务效果需验证，不能把“保留高方差”直接解释为“保留预测必需的一切”。

PCA 也不是解决过拟合的通用替代品。若原特征维度可接受，先建立原始数据基线，再比较是否值得增加降维流程。

# 【机器学习15】强化学习入门、Q-Learning、贝尔曼方程

对应原文件：[第15篇 HTML](<吴恩达机器学习完整笔记/【机器学习15】强化学习入门、Q-Learning、贝尔曼方程 p129-137.html>)。

## 一、强化学习入门

### 1.1 强化学习的基本概念

**强化学习（Reinforcement learning，RL）**研究智能体如何通过与环境交互，学习一系列行动，使预期累计奖励尽可能大。

**智能体（Agent）**是做决策的一方，**环境（Environment）**根据行动产生状态变化和奖励。它与监督学习的区别在于：通常没有每个状态下的“正确行动标签”，而是通过行动后获得的结果学习。

直升机控制中，很难逐一标注所有飞行状态的正确操作；可以定义平稳飞行、到达目标、避免坠毁等反馈，训练控制策略。当前行动还会影响未来能见到哪些状态，因此这是一类**序贯决策**问题。

### 1.2 强化学习的应用

课程举例包括机器人控制、生产调度、游戏和交易决策等。这些场景的共同点是决策会改变后续状态，单步看来不利的行动可能带来长期收益。

这里用于理解任务类型，不意味着任何具体场景都应优先采用 RL。是否适合还取决于可用交互、模拟条件和奖励是否可定义。

## 二、强化学习的关键术语

### 2.1 状态、行动与奖励

以六格火星车为例：

```text
左终点      中间位置                         右终点
  1 ----- 2 ----- 3 ----- 4 ----- 5 ----- 6
 +100                                    +40
```

**状态（State，s）**描述当前情形，本例是位置编号。**行动（Action，a）**是智能体可选择的操作，本例是向左或向右。**奖励（Reward，r）**是一次转移得到的即时反馈。

为避免原文计算口径混用，本章统一规定：**采取行动到达下一状态后发奖，到达1或6后立即终止，终止后不再重复发奖**。

一次经验记作：

$$
(s_t,a_t,r_{t+1},s_{t+1})
$$

例如 $$(4,left,0,3)$$、$$(2,left,100,1)$$。奖励可以依赖状态、行动及下一状态；本例简化为由到达位置决定。

**回合（Episode）**是从初始化开始到终止的一段完整交互。终止状态不再产生新的行动价值。

### 2.2 回报与折扣因子

**回报（Return）**是从当前时刻开始，未来奖励的累计值。**折扣因子（Discount factor，γ）**决定远期奖励权重：

$$
G_t=r_{t+1}+\gamma r_{t+2}
+\gamma^2r_{t+3}+\cdots
$$

$$γ$$ 小时更偏重近期；$$γ$$ 接近1时更重视远期。在持续任务中，折扣也有助于使累计值有限；有限回合也可以在适当条件下使用 $$γ=1$$。

从状态4一路向左，奖励序列为 $$[0,0,100]$$：

$$
G=0+\gamma\cdot0+\gamma^2\cdot100
$$

$$γ=0.5$$ 时为 $$25$$，$$γ=0.9$$ 时为 $$81$$。一路向右的奖励为 $$[0,40]$$，回报为 $$40γ$$。

**数值修正**：原文部分算例在奖励序列开头多放了一项0，并与“到达下一状态立即发奖”的公式混用。本笔记按上述统一约定重算；若采用另一种发奖时刻，必须连同回报定义、贝尔曼方程和表格一起调整。

### 2.3 策略

**策略（Policy，π）**规定智能体在某个状态如何选择行动。确定性策略写为 $$a=π(s)$$；随机策略写为 $$π(a|s)$$，表示各行动的选择概率。

例如“在2、3、4向左，在5向右”是一个确定性策略。策略是行为规则，奖励是环境反馈，二者不是同一个函数。

### 2.4 强化学习的目标

寻找能最大化期望折扣回报的策略：

$$
\pi^*\in\arg\max_\pi\mathbb E_\pi[G_t]
$$

实际通常针对初始状态分布评价策略，而不是只看某一条幸运轨迹。最优策略的具体形式取决于转移规律、奖励和折扣因子。

### 2.5 术语总结

| 术语 | 火星车 | 直升机 |
|---|---|---|
| 智能体 | 控制火星车的决策系统 | 飞行控制系统 |
| 状态 $$s$$ | 当前格子 | 位置、速度、姿态等 |
| 行动 $$a$$ | 左/右 | 控制输入 |
| 奖励 $$r$$ | 到终点得分 | 平稳、到达、坠毁等反馈 |
| 回报 $$G$$ | 未来得分的折扣累计 | 未来反馈的折扣累计 |
| 策略 $$π$$ | 每个位置怎样走 | 每个飞行状态怎样控制 |

## 三、Q-Learning 算法

### 3.1 马尔可夫决策过程

**马尔可夫决策过程（MDP）**是描述序贯决策环境的常用数学模型，包含状态空间、行动空间、转移规律、奖励和折扣因子。

**马尔可夫性质**：给定当前状态与行动后，下一步的分布不再需要额外依赖过去历史。并不是说历史毫无影响，而是历史相关信息应已被当前状态充分概括。

例如仅给直升机位置、不给速度，可能不足以预测下一步；加入速度等信息，可以使状态表示更接近所需条件。

### 3.2 状态-行动价值函数

**状态-行动价值函数（Q-function）**衡量“当前在状态 $$s$$ 先执行行动 $$a$$，之后按某策略行动”的预期回报：

$$
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a]
$$

**最优 Q 函数**：

$$
Q^*(s,a)=\max_\pi Q^\pi(s,a)
$$

它的含义是：第一步固定执行 $$a$$，后续都按最优方式行动。课程常简写为 $$Q(s,a)$$，但要分清某策略的 Q、正在学习的估计值与真正的 $$Q*$$。

Q 是累计回报的数值，不是行动概率，可能为负，也不要求各行动值相加为1。

### 3.3 利用 Q 函数选择行动

$$
V^*(s)=\max_aQ^*(s,a),\qquad
\pi^*(s)\in\arg\max_aQ^*(s,a)
$$

$$max$$ 返回最大价值，$$argmax$$ 返回取得该价值的行动。若有多个最优行动，策略可以选其中之一。

基准环境 $$γ=0.5$$、左右终点奖励100与40下：

| 状态 | $$Q*(s,left)$$ | $$Q*(s,right)$$ | 最优行动 |
|---|---|---|---|
| 2 | 100 | 25 | 左 |
| 3 | 50 | 12.5 | 左 |
| 4 | 25 | 20 | 左 |
| 5 | 12.5 | 40 | 右 |

例如 $$Q*(2,right)=0+0.5×V*(3)=25$$：第一步先向右，之后可以改向左，并非被迫一路向右。

### 3.4 Jupyter Notebook 实验分析

沿用原文的四组实验，按一致的到达发奖约定，状态4的结果为：

| 实验 | $$γ$$ | 右终点奖励 | $$Q*(4,left)$$ | $$Q*(4,right)$$ | 最优行动 |
|---|---|---|---|---|---|
| 基准 | 0.5 | 40 | 25 | 20 | 左 |
| 降低右奖励 | 0.5 | 10 | 25 | 6.25 | 左 |
| 增大折扣因子 | 0.9 | 40 | 81 | 65.61 | 左 |
| 减小折扣因子 | 0.3 | 40 | 9 | 12 | 右 |

这些数值由贝尔曼最优关系重新计算，不能直接照搬原文截图下的混合数值。

还有一个关键区别：**Q 值允许第一步以后改变方向**。$$γ=0.9$$ 时，从4先右到5，之后最优行动是回左追求100，因此：

$$
Q^*(4,right)=0.9V^*(5)=0.9\times72.9=65.61
$$

若强制之后一直向右，回报才是 $$0.9×40=36$$。后者是指定路径的回报，不是该状态-行动对的最优 Q 值。

总体规律：终点奖励、步数成本和折扣都会改变策略；提高远见程度不意味着所有 Q 值必然按相同比例增长。

### 3.5 贝尔曼方程

**贝尔曼方程（Bellman equation）**把长期价值分解成“即时奖励＋折扣后的后续价值”。确定性转移下：

$$
Q^*(s,a)=r+\gamma\max_{a'}Q^*(s',a')
$$

若 $$s'$$ 已终止，后续项为0，因此直接进入左终点的 Q 为100。

从回报定义推导：

$$
G_t=r_{t+1}+\gamma
\underbrace{(r_{t+2}+\gamma r_{t+3}+\cdots)}_{G_{t+1}}
$$

第一步得到即时奖励，剩余部分就是从下一状态继续行动的价值。最优情况下，下一状态选择最大 Q。

**Q-Learning**通过观测到的转移，逐步更新当前 Q 估计：

$$
Q(s,a)\leftarrow Q(s,a)+\alpha
\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right]
$$

方括号称为**时序差分误差（TD error）**。若旧值10、奖励2、下一状态最大值20、$$γ=0.9,α=0.1$$，则新值为 $$10+0.1×(2+18-10)=11$$。

注意 $$α$$ 控制学习步长，$$γ$$ 控制未来奖励折扣，二者作用不同。

## 四、随机环境

**确定性环境**中，同一状态行动产生固定结果；**随机环境**中，下一状态或奖励有随机性。例如向左操作有90%概率左移、10%概率打滑右移。

此时优化的是期望回报：

$$
Q^*(s,a)=\mathbb E_{r,s'\mid s,a}
\left[r+\gamma\max_{a'}Q^*(s',a')\right]
$$

同一行动的单次结果可能好也可能差，不能用一次轨迹判断策略优劣。Q-Learning 可利用采样到的转移构造 TD 目标，而不必事先知道完整转移概率；学习是否收敛仍依赖探索、步长等条件。

对应原文件：[第16篇 HTML](<吴恩达机器学习完整笔记/【机器学习16】连续状态空间、深度Q网络DQN、经验回放、探索与利用 p137-p144.html>)。

## 一、连续状态空间下的强化学习

**离散状态空间**由有限或可数状态构成，例如火星车位置。**连续状态空间**包含可连续变化的变量，例如坐标、速度、角度，无法为每个精确状态建立有限 Q 表。

卡车状态可写为：

$$
s=[x,y,\theta,\dot x,\dot y,\dot\theta]
$$

直升机可包含三维位置、三个姿态角以及对应线速度和角速度，形成约12维表示。

需要用**函数近似（Function approximation）**代替查表，使模型能够对未见过的相近状态给出价值估计。神经网络就是一种近似器，但使用近似器也会带来训练稳定性问题。

注意区分**连续状态**与**连续行动**。状态连续、行动只有四种时仍可以使用本章的多输出 DQN；连续行动不能简单对所有行动枚举取最大值，通常需要其他方法或处理。

## 二、深度强化学习：神经网络与 Q-Learning 的结合

**深度强化学习（Deep RL）**将深度网络用于策略、价值或环境模型等组件。本章重点是以网络近似 Q 函数的 **DQN（Deep Q-Network）**。

### 2.1 案例研究：月球登陆器

课程示例的目标是控制登陆器平稳降落。状态包含8个分量：

| 分量 | 含义 |
|---|---|
| $$x,y$$ | 位置 |
| $$vx,vy$$ | 线速度 |
| $$θ,ω$$ | 角度与角速度 |
| $$l,r$$ | 左右腿是否接触地面 |

其中前六个为连续量，最后两个为布尔量，因此准确说是**包含连续变量的混合状态向量**，并非八个分量全都连续。

离散行动包括不点火、左侧推进、主推进、右侧推进。奖励通常围绕接近目标、平稳着陆、坠毁与燃料消耗设计；原文中的具体分数属于课程环境示例，实际应按所用环境定义核对。

策略应优化整个回合的折扣回报，而不是只追求当前步的低燃料消耗，否则可能省下燃料却无法安全着陆。

### 2.2 使用神经网络近似 Q 函数

第一种方式把 $$(s,a)$$ 一起输入：

$$
Q_\theta(s,a)=\mathrm{NN}_\theta([s,\operatorname{onehot}(a)])
$$

本例状态8维、行动编码4维，总输入12维，可用 $$12→64→64→1$$ 网络输出一个 Q 值。

选择行动时要评价四个 $$(s,a)$$ 组合。这四个输入也能组成一个批次计算，不一定需要四次独立 API 调用，但仍对每个组合执行相应计算。

### 2.3 学习过程：将强化学习问题转化为监督学习

从经验 $$(s,a,r,s',terminated)$$ 构造回归目标：

$$
y=r+\gamma(1-d)\max_{a'}Q_{\bar\theta}(s',a')
$$

$$d=1$$ 表示真正终止，未来价值为0。$$Q_{\bar\theta}$$ 是较稳定的目标网络，在线网络 $$Q_\theta$$ 拟合目标：

$$
L(\theta)=\frac1B\sum_{i=1}^{B}
\left(Q_\theta(s_i,a_i)-y_i\right)^2
$$

这里使用目标网络的原因在2.8节展开。若只用当前网络自身生成目标，是更直接但可能更不稳定的自举方式。

**自举（Bootstrapping）**指用当前价值估计构造另一个价值估计的学习目标。这与 Bagging 中的 Bootstrap 采样不是同一个概念。

这些 $$y$$ 不是真实人工标签，而是奖励加估计值形成的 TD 目标。回归更新看起来像监督学习，但数据来自策略交互、目标还会随训练变化，因此整体仍是强化学习。

### 2.4 学习算法：经验回放

**经验回放（Experience replay）**把过去交互存入缓冲区，训练时随机采样一批，而不是只按刚发生的时间顺序更新。

一次完整循环：

1. 根据当前行为策略选择行动。
2. 执行行动，获得奖励、下一状态与终止信息。
3. 将经验存入回放缓冲区，容量满时可移除最旧记录。
4. 随机采样 mini-batch，计算 TD 目标。
5. 更新在线网络，再按规则更新目标网络。
6. 回合终止时重置环境，继续收集。

原文的缓冲区10000条、批量1000条是示意参数，不是 DQN 固定要求。

回放的两个作用是**减弱连续数据相关性**和**重复利用经验**。它不能保证样本完全独立同分布，也不会自动消除早期策略与当前策略之间的分布差异。

### 2.5 改进的神经网络架构与实现

有限离散行动下，更常见的架构只输入状态，一次输出全部行动价值：

$$
s\longmapsto
[Q_\theta(s,a_1),Q_\theta(s,a_2),
Q_\theta(s,a_3),Q_\theta(s,a_4)]
$$

可用 $$8→64→64→4$$ 网络，输出层为**线性**。四个输出不是概率，不使用 Softmax；最大值位置给出贪心行动。

训练时，只提取经验中**实际执行行动**对应的输出，与该条经验的 TD 目标比较。不能把一条经验的同一个目标强行赋给四个行动。

下面集中给出网络定义与一次小批量更新，连接本章各步骤：

```python
import tensorflow as tf

def make_q_network():
    return tf.keras.Sequential([
        tf.keras.Input(shape=(8,)),
        tf.keras.layers.Dense(64, activation="relu"),
        tf.keras.layers.Dense(64, activation="relu"),
        tf.keras.layers.Dense(4),
    ])

def train_dqn_batch(online, target, optimizer, states, actions,
                    rewards, next_states, terminated, gamma=0.985):
    states = tf.convert_to_tensor(states, dtype=tf.float32)
    next_states = tf.convert_to_tensor(next_states, dtype=tf.float32)
    actions = tf.reshape(tf.cast(actions, tf.int32), [-1])
    rewards = tf.reshape(tf.cast(rewards, tf.float32), [-1])
    terminal_mask = tf.reshape(
        tf.cast(terminated, tf.float32), [-1]
    )
    next_values = tf.reduce_max(
        target(next_states, training=False), axis=1
    )
    targets = tf.stop_gradient(
        rewards + gamma * (1.0 - terminal_mask) * next_values
    )
    with tf.GradientTape() as tape:
        all_q = online(states, training=True)
        selected_q = tf.gather(
            all_q, actions, axis=1, batch_dims=1
        )
        loss = tf.reduce_mean(tf.square(selected_q - targets))
    parameters = online.trainable_variables
    gradients = tape.gradient(loss, parameters)
    optimizer.apply_gradients(zip(gradients, parameters))
    return loss
```

开始训练前，创建两个同结构网络，并用 $$target.set_weights(online.get_weights())$$ 同步初值。之后目标网络不直接接受这一步损失的梯度更新。

### 2.6 核心挑战：探索与利用的平衡

**利用（Exploitation）**选择当前估计最好的行动；**探索（Exploration）**尝试其他行动，以发现更好的可能。

**ε-贪心策略（Epsilon-greedy）**：

$$
a=\begin{cases}
\text{随机行动},&\text{概率 }\epsilon\\
\arg\max_{a'}Q_\theta(s,a'),&\text{概率 }1-\epsilon
\end{cases}
$$

随机分支通常包含所有行动，所以即使进入探索分支，也可能刚好选中贪心行动。

可以从较大 $$ε$$ 开始逐步降低，保留一定探索。衰减过快可能漏掉有效策略，始终过大则可能影响回报；退火本身不保证学到最优策略。

### 2.7 训练细节：Mini-batch 梯度下降

每次从回放缓冲区抽取 $$B$$ 条经验，计算平均损失并更新一次。这里 $$B$$ 是训练批量，缓冲区容量则决定保留多少历史，两者是不同参数。

小批量使单次更新不必处理整个缓冲区，但仍有梯度噪声。批量、更新频率与环境交互频率都会影响训练效率和稳定性。

**终止与时间截断要区分**：环境真正终止时不再自举；若只是外部时间上限截断，是否保留下一状态价值应按任务定义判断，不能无条件把所有“停止采样”都当作终止。

### 2.8 训练细节：软更新

在线网络参数 $$θ$$ 频繁变化，若目标也立刻随之大幅变化，相当于不断追逐移动目标。**目标网络（Target network）**用更新较慢的参数 $$\bar θ$$ 产生 TD 目标。

**软更新（Soft update）**：

$$
\bar\theta\leftarrow\tau\theta+(1-\tau)\bar\theta
$$

$$τ$$ 小时每次只向在线参数靠近一点。$$τ=1$$ 相当于完整复制。另一种合法做法是隔一定步数硬复制一次，不是只有软更新才能使用。

```python
def soft_update(online, target, tau=0.001):
    for online_weight, target_weight in zip(
        online.weights, target.weights
    ):
        target_weight.assign(
            tau * online_weight
            + (1.0 - tau) * target_weight
        )
```

不要把目标网络更新与优化器更新混淆：前者平滑复制参数，后者根据梯度改变在线参数。TD 目标通常要停止梯度，不反过来沿目标分支优化。

### 2.9 强化学习的局限性

- **交互成本**：很多问题需要大量试验，真实设备交互可能昂贵或难以重置。
- **奖励设计**：奖励只是目标的数值代理，设计不当可能诱导偏离真实意图的行为。
- **训练稳定性**：函数近似、自举和不断变化的数据分布组合，可能使学习不稳定。
- **模拟到现实差距**：传感器误差、时延和动力学差异可能让模拟策略失效。
- **评价困难**：单次回报波动较大，需要多个回合并关注失败情形。

评估 DQN 不应只看训练 MSE，还应看独立评估回合的回报分布、任务成功率和行为表现。较小 TD 损失不自动等于学到了好策略。
